# 使用 Cookie-Editor 导入哔哩哔哩 Cookie

当前登录入口仅提供 Cookie 导入，可粘贴文本或选择文件。首次启动时进入登录窗口；更新登录状态时从“设置”列表末尾点击“重新登录”。

## 1. 安装扩展并登录网页

1. 使用 Microsoft Edge 打开 [Cookie-Editor 扩展商店页面](https://microsoftedge.microsoft.com/addons/detail/cookieeditor/neaplmfkghagebokkhpjpoebhdledlfi)，点击“获取”并按浏览器提示安装。
2. 在同一浏览器中打开 [哔哩哔哩主页](https://www.bilibili.com)，登录希望在播放器中使用的账号，确认页面显示已登录头像。
3. 保持哔哩哔哩标签页为当前页面，从 Edge 工具栏的“扩展”菜单打开 Cookie-Editor。如果扩展请求当前站点访问权限，请允许访问哔哩哔哩页面。

## 2. 导出 Cookie Header

1. 在 Cookie-Editor 中点击 **Export（导出）**。
2. 选择 **Header String**（Cookie 请求头字符串；扩展语言或版本不同，显示名称可能略有不同）。不要选择 JSON 或 Netscape 格式。
3. 导出的内容会复制到剪贴板，应为 `名称=值; 名称=值` 形式的完整字符串，其中必须包含非空的 `SESSDATA`。请保留完整导出结果，不要只复制某一项或手动解码其中的字符。

仅用于说明格式的无效示例：

```text
SESSDATA=示例值; bili_jct=示例值; DedeUserID=示例值
```

Cookie 是账号登录凭据。请勿发给他人、贴进问题反馈或上传到代码仓库。

## 3. 导入播放器

### 直接粘贴

回到播放器登录窗口，把剪贴板中的完整内容粘贴到“粘贴 Cookie”输入框，点击“验证并导入”。验证成功后会自动保存到页面显示的路径，文件名为 `bilibili.cookie.txt`，随后进入动态页。

### 从文件导入

用纯文本编辑器将导出的 Header String 保存为 UTF-8 文本文件，例如 `bilibili.cookie.txt`。在登录窗口点击“选择 Cookie 文件”并选中该文件；选择后自动验证并保存到当前配置使用的位置。源文件可以放在其他目录，无需自行查找或覆盖应用配置目录。

导入失败会保留原有凭据。页面的“凭据保存在”显示实际目标路径；成功后无需再次手动复制文件。

## 常见问题

- **找不到 SESSDATA 或导出结果为空**：确认当前标签页是已登录的 `www.bilibili.com`，刷新网页后重新打开扩展，并检查扩展的站点访问权限。
- **内容以 `[` 或 `{` 开头**：通常选成了 JSON，请重新选择 Header String 导出。
- **提示 Cookie 无效或过期**：在浏览器重新登录哔哩哔哩，再导出最新内容。网页退出登录后，之前导出的凭据也可能失效。
- **提示网络或保存错误**：按提示检查网络及页面显示的目标目录写入权限，再重试。
- **暂时不登录**：点击“稍后登录，继续使用”，进入下载管理与本地媒体库。
- **使用 Windows 原生历史服务**：更换 Cookie 后按 [Windows 原生服务与 UAC](Windows原生服务与UAC.md) 重新保存计划，确保服务具备读取权限。
