# 下载管理与本地媒体库

日期：2026-09-19。用户已完成本轮验收并要求同步归档。主规格：`openspec/specs/download-manager/spec.md`；工作记录：`openspec/changes/archive/2026-09-19-add-download-manager/`。下文保留各阶段验证与手测记录；Windows 原生执行未单独确认，仍列为后续平台验证。

## 使用

- 普通视频卡片右键选择“下载”，或在播放器右上角点击截图左侧的下载按钮。下载当前条目对应分 P/分集；没有分 P 定位时下载首 P，不自动下载整季。
- 默认选择视频、弹幕与字幕；“视频”包含音轨并通过 FFmpeg 无损合并为 MP4，“仅音频”输出 M4A，二者互斥。下载弹窗提供清晰度选择，初始值来自设置，修改只影响本次任务。也可仅选弹幕/字幕。资源仍受服务端权限、地区、可用清晰度和是否提供字幕约束。
- 设置 → 下载设置：选择保存文件夹，默认是系统用户“下载”目录（QStandardPaths::DownloadLocation，通常 Windows 为 `%USERPROFILE%/Downloads`、macOS 为 `~/Downloads`）；偏好影响新建任务，旧任务保留目录和资源快照。
- 导航末尾“下载管理”分为下载中、媒体库；下载中显示 aria2 实际传输进度映射出的任务百分比，解析/合并/附件显示不定进度，可取消和重试。退出后未完成任务保留，重试重新解析临时流地址。
- 右上角“导入”选择本地视频/音频。媒体库保留源文件位置，不复制或移动原文件；重复路径去重。后台用 FFmpeg 优先提取内嵌封面，没有则提取第一帧，封面存放在应用缓存目录。
- 下载管理卡片右键仅提供“移除”。确认框默认不勾选“删除物理文件”，只删除记录；勾选后删除媒体、关联 XML/SRT 及任务临时文件，活动下载先停止。共享文件或权限导致删除失败时保留记录并提示，不清空整个目录。
- 媒体库刷新和点击前检查媒体是否存在、可读且非空，失效条目不可播放。内置播放器播放本地文件时自动加载同目录同名 `.xml` 弹幕，缺少跳过；已下载的 SRT 与内嵌/同名旁挂字幕在 CC 菜单中手动选择，始终默认关闭，不记忆上次选择。
- 本地播放无需 Cookie，不请求在线播放 API、不写在线播放进度库、不发送 B 站心跳。实际格式解码仍由 libmpv 判断，损坏媒体显示播放错误。

## 依赖与文件

macOS 可执行 `brew install aria2 ffmpeg`；系统 curl 随平台提供。Windows 安装对应架构的 aria2c/FFmpeg，可将可执行程序置于应用 `tools` 目录或在设置中指定完整路径。macOS Finder 启动也会检查 Homebrew 路径。当前发布脚本不捆绑这两个下载工具。

下载记录保存在应用数据目录独立 `downloads.sqlite`，与历史数据库隔离。测试通过隔离目录运行，不修改真实用户库。数据库只保存白名单视频基础资料、任务状态/资源选择及路径，不保存 Cookie、API 原始响应或签名媒体 URL；工具输入经进程标准输入传递，子进程原始输出不会展示或持久化。

同名输出使用时间戳隔离，不覆盖用户文件。全部所选资源成功后清理本任务 DASH `.m4s` 分轨及 `.complete`/`.aria2` 标记，仅留下正式媒体、XML 和 SRT；失败或取消时保留分轨供重试。清理使用准确文件名，不递归清空目录，不删除导入文件或其他任务文件；清理失败显示提示。FFmpeg 使用临时输出，成功才改名为正式文件，失败则回收临时输出。附件阶段重试复用已合并媒体，避免重复生成 MP4。XML 是 B 站当前存档接口返回的弹幕，不等于完整历史弹幕。B 站字幕 JSON 经系统 curl 获取后转换为 UTF-8 SRT。

媒体和附件显式直连，不继承环境代理；区域番剧仅详情/PGC API 使用请求级代理快照。aria2/FFmpeg/curl 通过 QProcess 参数数组启动，无 shell 字符串执行。

## 手测清单

1. 在普通视频、多 P 历史、番剧分集各打开下载对话框；确认播放器入口位于截图左侧、本地播放无在线下载按钮；修改四项资源选择后只有选中内容落盘。
2. 设置选择含中文/空格的目录，重启确认保持。缺 aria2/FFmpeg 时应清楚提示，修复工具路径后可重试。
3. 下载含音轨、弹幕、字幕的视频，确认 MP4 音画正常、XML/SRT 格式正确、媒体库播放有弹幕。无字幕视频应说明无可用字幕，其余资源正常。
4. 下载中取消、断网失败、关闭应用后重开，确认任务记录保留、状态明确、重试不会覆盖已有文件，完成任务转入媒体库。
5. 导入带同名 XML 的视频并播放，拖动进度和倍速检查弹幕同步；导入无 XML 视频应正常播放。重复导入同一路径不重复建卡。
6. 将已导入媒体临时移走，再刷新或点击，确认不可用提示且不尝试联网取流；恢复文件再刷新可以播放。
7. 主窗口最小尺寸、导航展开/收起、浅色/深色、中文/英文检查瀑布流、空态、进度及右上“导入”外边距。
8. 在 Windows 实测外部工具启动不弹控制台，系统下载文件夹解析正确，关闭应用后无残留下载子进程。

## 本地视频黑屏修复（2026-09-19）

症状为起播后黑屏、有声音且时间轴增长。样本 MP4 包含完整 H.264 视频和 AAC 音轨；根因在播放器启动顺序：本地文件在打开窗口前立即加载，此时 Qt Quick 尚未创建 libmpv 渲染上下文，mpv 因视频输出初始化失败禁用视频轨。

使用仓库红色 H.264 fixture 合成静音 AAC，在原生离屏 OpenGL 环境中复现：先加载、500ms 后建上下文时视频轨为 `no`，音频时间继续增长、渲染零帧；先建上下文再加载时视频轨正常并输出红色画面。这里的延时仅用于复现，修复没有使用固定等待。

现在渲染线程创建上下文成功后才通知控制器加载媒体。等待期间不消耗 CDN 候选超时；切播和关窗取消旧等待，旧内核的就绪/错误通知按绑定版本过滤。已初始化的内核可立即切播。该门控同时用于点播的 DASH/durl 与本地媒体，硬解配置保持原有 `auto-copy` / `auto-safe`。

复测请重新启动最新开发构建，从媒体库播放原视频，检查起播画面、声音、XML 弹幕、SRT、拖动与暂停；关闭播放器再打开一次，并快速切换两个本地视频。仅音频仍应正常播放。桌面窗口交互与 Windows 画面由用户手测。

## 实时进度、导入封面与移除（2026-09-19）

- aria2 每秒提供实际百分比；后台读取输出并提取进度数值，使用有界缓存、限频通知，不记录包含媒体地址的原始输出。视频/音频按资源阶段映射至任务 90%，解析、合并和附件使用不定进度，所有资源成功后才显示完成。单卡片接收 `taskProgress`，进度路径只改内存，不做 SQLite 写入、文件检查或重建瀑布流。
- 下载状态保存和记录移除使用同一后台串行队列，避免数据库锁阻塞 UI，并保证较新的完成状态覆盖旧快照。已接受的后台写入在退出时等待完成。
- FFmpeg 优先提取 MP4 内嵌封面及可识别的 Matroska 图片附件，没有时使用第一帧；纯音频没有内嵌图片时保留空封面。只允许本地输入协议，总处理限时 20 秒，JPEG 长宽不超过 400px，缓存按规范路径、大小、修改时间区分。启动后会给既有导入记录补提取；失败不影响播放，源文件不变。
- 移除对话框每次打开重置“不删除”。删除只使用条目的准确文件路径；包含已关联的语言字幕及同名 XML/SRT，不递归删除目录，不删除其他记录共享文件。取消下载及封面提取并确认子进程结束后再删除，避免 Windows 文件句柄占用；晚到进度、封面或完成结果不能重新插入记录。默认只删除记录，已有媒体和附件可再次导入。
