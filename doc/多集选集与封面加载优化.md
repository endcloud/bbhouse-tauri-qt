# 多集选集与封面加载优化

日期：2026-09-18。OpenSpec：`optimize-episode-switch-and-cover-thumbnails`。用户已确认多集切播、封面加载及番剧竖版封面补修测试 pass，已于 2026-09-18 同步主规格并归档。

## 选集卡顿定位与修复

定位到两条独立的主线程开销，均通过离线回归复现：

1. 选集项继承 `FluMenuItem`，其默认高度为 `visible ? implicitHeight : 0`。弹层隐藏时所有条目高度为 0，ListView 为填满视口创建全部分集。5000 集 fixture 实际生成 5000 个 delegate；打开/关闭及更新选择都承担不必要的对象和绑定开销。选集行显式固定 36 逻辑像素高度，使隐藏时仍保留正确布局尺寸，继续使用原有虚拟化 ListView 和菜单交互。修复后同一 fixture 仅保留约 20 个 delegate。
2. `MpvClient` 在 FILE_LOADED 事件中通过同步 `mpv_command(audio-add)` 挂远程 DASH 音轨，网络下载/探测期间阻塞 GUI 事件循环。改用 `mpv_command_async`，成功完成后才通知播放就绪；失败继续走既有错误/候选回退管线。新装载、停止、主媒体错误与销毁会取消旧音轨命令；完成回调检查装载代数和 playlist entry ID，避免过期音轨误报新选集状态。

播放地址 API 仍在线程池执行，DASH 音视频保持直连。没有修改风控、代理、权益或续播规则；网络缓冲可能仍存在，但远程音轨等待不会再同步占住 GUI 线程。

## 封面请求

此前并非所有卡片都请求原图：HistoryCard/SeasonCard 按显示尺寸与屏幕 DPR 生成较大的转码图、优先 AVIF，且关闭缓存，失败后回退原图；特别关注合集、专栏及直播卡片直接请求原图。个人空间复用特别关注页面组件。

统一 `Format.cardCoverThumbnailUrl()`：

- 横版卡片的 B 站图片 CDN 路径使用固定 `@400w_225h_1c.webp`，已有转码后缀替换，保留查询参数/片段，避免叠加后缀。
- 覆盖本地/在线历史、动态、稍后再看、流行、番剧、个人空间、特别关注投稿/合集/合集内视频/专栏、直播以及播放器列表封面。
- 图片缓存开启，加载失败显示原有失败/重试状态，不自动追加一次全尺寸原图下载。Windows 打包清单已保留 `qwebp.dll`。
- 空地址、本地资源和不支持 B 站转码语法的外部地址保持原样。
- 原始模型与放大预览的 `baseUrl` 不变；原图下载也保持原行为。番剧页竖版卡片保留既有布局，按用户后续反馈单独使用 `@.webp`，仅转换格式，不在 CDN 限制宽高或裁剪。
