## 特别关注头像抗锯齿

参考库原来使用 `OpacityMask`。项目迁移到 `MultiEffect` 后仅启用 `maskEnabled`，默认 `maskSpreadAtMin=0` 会把遮罩半透明边缘近似阈值化；单独增加内容层分辨率不能恢复丢失的 alpha 过渡。

Qt 6 `FluClip` 现在对下限遮罩使用 `maskThresholdMin=0.5` 与 `maskSpreadAtMin=1.0`，保留平滑 alpha 过渡；内容层、遮罩纹理与 QPainter 来源使用匹配的采样尺寸，并启用平滑采样。头像同时开启 mipmap，加载/错误状态使用小尺寸人物占位，避免默认重试按钮挤进圆形区域。头像添加 UP 名称无障碍标签。

这是根据绘制链路修复，不等同于已完成 macOS/Windows 视觉验收。`FluClip` 仍沿用上游的软件渲染降级：软件 backend 不启用 GPU mask；本轮重点为正常 Metal/D3D/OpenGL 图形后端。

## 手测清单

- 窗口按 880×560、1200×720、最大化检查；每个尺寸分别展开/折叠导航。检查顶部搜索、菜单按钮、标题、右上刷新、底部分页及滚动条，不应互相覆盖。
- 在简体中文/English、亮色/暗色中逐页切换；主题/语言选项、较长 UP 名、较长标题及错误提示应截断或换行，不能侵入导航。
- 动态页切全部/视频，加载多个分区后缩小窗口，检查分类换行后卡片仍位于筛选区下方。
- 本地历史开始/取消同步，检查状态与计数；三类分页页检查首页/末页禁用、较大页数、搜索清空结果及再恢复。
- 特别关注头像在 Retina 2×、Windows 100%/125%/150%/200% 缩放检查，留意圆弧毛边、白/黑边、拉伸以及跨显示器拖动后的清晰度。检查头像条和管理弹层中的两种尺寸。
- 特别关注管理窗口检查头像加载失败占位、长昵称/签名、列表拖动滚动条、搜索/加载更多/保存/取消；最小窗口下底部按钮必须可见可点。
- 特别关注逐个检查投稿、合集、展开合集、专栏；专栏卡片行距不能出现一整张封面的空白，展开合集后底部分页应消失并释放空间。
- 番剧详情含长简介、长分集标题与大量分集时，检查弹层滚动、关闭和播放入口；缩小窗口确保底部操作不被裁掉。
- 设置展开 About，检查内容与边框间距、复制按钮、版本文字换行与右键菜单。
- 任意卡片点击封面打开预览，缩放窗口/最大化，再关闭；预览应持续适配窗口，且不打开卡片链接。
- 清空搜索结果、切换空列表再恢复数据，检查列表无陈旧长空白、回顶按钮不残留错误状态。
