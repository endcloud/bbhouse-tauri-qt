# 弹幕显示设置与相似合并

对应 OpenSpec：`add-danmaku-display-settings`。设置入口为“设置 → 播放与弹幕”，两种弹幕实现都使用同一组偏好。

## 设置与默认值

用户于 2026-09-18 确认以下行为，保留原有默认显示效果。

| 设置 | 范围 | 默认 / 行为 |
|---|---|---|
| 默认弹幕状态 | 开 / 关 | 默认开；与播放器按钮和 D 键双向同步，记住最后状态 |
| 弹幕不透明度 | 0–100% | 100%；文字和描边一起变化，0% 完全隐藏 |
| 弹幕字号 | 12–48 逻辑像素 | 25；原始弹幕自身的字号比例继续保留，平台字体不变 |
| 弹幕显示区域 | 顶部 1/4、半屏、全屏 | 全屏；所有模式完整文字都约束到指定区域，底部弹幕位于该区域底部车道 |
| 弹幕密度上限 | 不限、20、40、60、80、100 条 | 不限；按同时在屏条数计算，所有模式共享总数 |
| 合并相似弹幕 | 开 / 关 | 默认关；同模式、固定 10 秒窗口，显示原文与 `×数量` |
| 弹幕实现 | 场景图文字、预缓存图像 | 保持既有偏好，未设置时为场景图文字 |

“不限”仍遵守车道防碰撞、文字/图片准备预算和内部最大活跃数，并不保证服务端每一条弹幕都显示。密度不足时跳过额外条目，不排队到几秒后再显示；合并的一组按一条计算。

设置即时通知当前弹幕层并持久化，不重载视频或改变播放/暂停状态。设置页窄窗口自动切为单列，区域选项可换行，使用已有 FluToggleSwitch、FluSlider、FluRadioButton、FluComboBox。中文和英文均已覆盖。

## 合并方式

参考 pakku.js 的短时间候选窗口、文本规范化和数量提示，使用独立 Qt 实现；不等同于 pakku 全功能移植。具体来源、许可证、算法差异和性能量级见 [pakku 参考与取舍](pakku弹幕合并参考.md)。

- 以首条为时间基准，10 秒内（包含边界）相同模式才可合并，后来的重复不会延长窗口。
- 规范化全半角、大小写、空白、末尾标点，仅用于比较；显示保留首条原文、时间和样式。
- 短文本只做规范化后的精确匹配，较长文本允许有限编辑差异，不合并不同数字序列。`666…`、`233…` 是单独支持的惯用重复表达。
- 合并不是语义理解；相似长句仍可能误合并，关闭开关即可恢复原始列表。
- 后台每引擎最多一个合并任务。快速操作只处理最新数据；旧视频结果不能覆盖新视频。渲染帧循环不运行相似度比较。
- 原始与已合并列表分开保存，关闭合并或切渲染实现不会反复追加数量。预缓存图像截短长文本时保留数量后缀。

首次开启或切视频后，后台处理完成前弹幕层可能短暂留白。修改字号、区域、密度或合并会重新排布弹幕；预缓存图像继续采用前向调度，不补播 seek 前或当前时刻之前的条目。合并组在首条时间显示，seek 到组内后段时不会单独重放组中成员。

## 持久化与维护

`AppPreferences` 使用独立通知属性。旧键 `App.Player.DanmakuOn` 保持兼容，新增 `App.Player.DanmakuOpacity`、`App.Player.DanmakuFontSize`、`App.Player.DanmakuArea`、`App.Player.DanmakuDensity`、`App.Player.DanmakuMergeSimilar`。

页面创建不写设置。类型错误、损坏值有默认回退，滑块写入钳制范围，区域/密度非法枚举拒绝写入；通用 `setValue` 对这些键也走同一验证和通知链。

## 手测清单

请在两种弹幕实现中各检查一次，建议选重复弹幕较多且包含滚动/顶部/底部弹幕的视频。

1. **设置同步**：设置页开关弹幕，播放器按钮与 D 键反向操作，确认状态互通。关闭重开播放器及应用后，全部设置保持。
2. **不透明度与字号**：不透明度拖到 0%、50%、100%，检查描边也随之变化；字号在 12/25/48 间切换，检查中文、英文、emoji、Retina/Windows 缩放下的完整文字和清晰度。
3. **显示区域**：切顶部 1/4、半屏、全屏，检查三类弹幕均不越出区域，尤其大字号、窗口缩放和全屏。
4. **密度**：密集内容设为 20 条，再切不限；确认遮挡数量变化，设置变化不影响视频、音频及暂停状态，不在后续空档补发积压弹幕。
5. **相似合并**：开关合并，确认刷屏合为一条并显示 `×数量`；不同短句、年份数字和不同模式仍独立，关闭后恢复。留意长文本数量标记和可能的误合并。
6. **切换边界**：暂停时调整设置，连续切合并、切实现、seek、切视频、关闭播放窗口，检查无旧片弹幕回流、死锁或异常起播卡顿。
7. **UI 与截图**：明暗主题、窄窗口、中英文检查对齐和说明换行；顶部截图仍只有视频画面，不含弹幕和控件。
