# 流行页面与每周必看选期

日期：2026-09-18。OpenSpec：`add-popular-page`。用户已确认功能及两轮 UI 补修验收通过，已于 2026-09-18 同步主规格并归档。

## 已实现

- 左侧导航在动态后增加“流行”，修正参考 Tauri 页的“留下”错名。包含综合热门、每周必看、入站必刷、排行榜四档。
- 综合热门每次请求 20 条，滑动到底或点击“加载更多”续载，跨页按视频键去重；末页尊重服务端 `no_more`。搜索只筛已加载内容，不因空搜索结果自动拉取更多。稳定列表模型增量追加，加载中和失败保留原卡片与滚动位置。
- 每周必看先加载全部期数目录，按期号倒序列出“第 N 期 · 日期/名称”，默认最新期；选择历史期显式传 `number`，校验返回期号。历史期分别缓存，刷新当前内容不跳回最新期；期数右侧按钮独立刷新目录，目录仍含该期时保持选择。
- 入站必刷、每周期内容与排行榜先按完整列表搜索，再每页 30 条本地分页。搜索提交/清空、切档和切期回首页；离开页面或进入作者空间后返回，原页面保持搜索、选择、页码和滚动。
- 排行榜包含参考页的 19 个常规分类和全站音乐榜；其中番剧、国创、纪录片、电影、电视剧使用 PGC 专用榜单。音乐榜跨年份按发布时间选最新期，优先关联稿件，否则整组采用 MV 字段，仅音频且无视频 ID 的条目不进入点播列表。
- 视频卡片显示封面、标题、推荐理由（接口提供时）、作者、时长、播放/弹幕统计，排行榜保留原名次。播放量不占用历史观看次数，不显示伪造的观看时间。节目卡片不显示不存在的 UP 主。
- 封面点击预览、主体点击原生播放、作者行进入个人空间、右键打开原链接。PGC 榜单常只有整季 ID，使用独立 `PopularSeasonController` 取详情，进入现有整季播放及选集流程，按既有观看分集续播；不与追番页的详情请求互相覆盖。
- 各请求捕获选择快照并校验代数。快速切期、切榜的旧结果不会覆盖当前内容；刷新失败保旧，错误状态与空态分别呈现。页面隐藏或切选择时放弃尚未完成的起播意图。

## 接口与参考差异

功能参考：Tauri `src/components/PopularSection.vue`、`src/stores/popular.ts`、`src/bili_api/popular.ts`。外部参考仓库只读。

| 内容 | GET 端点 / 参数 | 参考与处理 |
| --- | --- | --- |
| 综合热门 | `/x/web-interface/popular?pn=N&ps=20` | `docs/video_ranking/popular.md`，使用 `no_more` 判断结束 |
| 每周期数 | `/x/web-interface/popular/series/list` | 同文档的每周必看目录；不假设连续期号，不按日期推算 |
| 指定周刊 | `/x/web-interface/popular/series/one?number=N` | 显式选期，校验 `config.number`；原 Tauri 缺该参数与选择器 |
| 入站必刷 | `/x/web-interface/popular/precious` | `docs/video_ranking/precious_videos.md`，完整列表及说明 |
| UGC 榜 | `/x/web-interface/ranking/v2?rid=N&type=all` | `docs/video_ranking/ranking.md` |
| PGC 榜 | `/pgc/season/rank/web/list?season_type=N&day=3` | API 文档没有覆盖该新接口，以只读 wiliwili `source/api/home_api.cpp`、`include/api/bilibili/api.h` 与公开响应补充；season_type 为 1/4/3/2/5 |
| 音乐期目 | `/x/copyright-music-publicity/toplist/all_period?list_type=1` | `docs/audio/rank.md`，字段名称为 `priod` |
| 音乐内容 | `/x/copyright-music-publicity/toplist/music_list?list_id=N` | 关联稿件与 MV 不混配身份、封面和作者 |

统一使用现有 `BilibiliApiClient` 直连和错误映射。目录、排行榜、音乐走普通 GET；综合热门、选期和必刷在 Cookie 非空时加 WBI。缺凭据文件允许匿名浏览，匿名请求不先强制访问会返回 -101 的 nav；已有但损坏的凭据文件显示现有明确错误。服务端风控仍可能拒绝匿名或登录请求，不自动循环重试。

## 手测清单

1. 启动 `build/bin/bbhouse-qt`，从动态进入流行。依次检查四档；热门滚动到底和手动续载不跳顶、不卡在加载中、不重复追加。
2. 每周必看默认最新期，选择较早期（可直接核对第 1 期），确认期数、说明和视频同步变化；快速切两期后只展示最后所选期。切回缓存期、刷新当前期、刷新期数目录均不误回最新期。
3. 检查目录失败/空、内容失败/空、断网刷新和恢复重试，成功旧列表应保留；目录错误不妨碍使用已缓存期数。
4. 周刊/入站必刷/排行榜多页时搜索仅在后页出现的标题或 UP，结果回首页；清空恢复。离页返回、进入作者空间再返回，搜索和位置保持。
5. 排行榜检查 UGC 分区、五类节目榜、全站音乐榜。普通视频主体起播；节目主体进入整季播放器并可选集；作者行只进空间、封面只预览，右键网页链接正确。发出剧集详情请求后立刻离页，不应随后弹出播放器。
6. 明暗主题、English、最小窗口、展开导航和长标题下，期数/榜单选择器、筛选、说明、错误和分页不重叠；统计不出现“观看 N 次”或“未知时间”。

## 手测反馈补修：紧凑布局（2026-09-18）

- 卡片沿用动态页的 300px 宽度与 16px 横向间距，网格整体居中，剩余宽度留在两侧；行高按已呈现卡片的最大实际高度加 16px 计算，移除原有偏大的固定高度。保留稳定模型与网格虚拟化。
- 底部页码、总条数和分页按钮合为一行；分页控件明确保留固有宽度，避免内部 Flow 将上一页、页码、下一页拆成多行。窄窗口适当减少页码按钮。
- 排行榜下拉框移至四档切换栏最右侧，额外留 12px 右边距；滚动条保持在内容区右侧。窄窗口的切换标签可省略，悬停显示全文。

## 手测反馈补修：下拉选项文字（2026-09-18）

每周必看和排行榜展开后没有文字，原因是内嵌 Qt6 `FluComboBox` 委托自行解析模型角色时得到空文本。改为显式声明选项索引并调用 Qt 原生 `textAt(index)`，与折叠时显示的标签使用同一解析路径；保留 FluentUI 明暗主题文字颜色。

`popular-page` 回归实际展开两个菜单，检查选项与期数/榜单标签一致、正文尺寸有效、文字与背景可区分，并覆盖两种主题和同数量期数目录刷新。新增检查在修复前失败、修复后通过。Release/Debug 构建、完整 CTest 30/30、OpenSpec 全部严格校验 24/24 通过，无 QML 运行警告。用户已确认下拉文字补修通过，并要求同步归档。
