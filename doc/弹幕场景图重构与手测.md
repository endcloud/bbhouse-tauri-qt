# 弹幕场景图重构与手测（2026-09-18）

> 验收更新（2026-09-18）：用户确认手测完全通过。下文“待手测”描述保留为交付时记录；本次 OpenSpec 清理记录见 [归档审计](OpenSpec积压清理与遗留差异.md)。

按照 bililocal 评估路线完成生产重构。当前弹幕使用 QQuickItem + QSGTextNode，移除 QQuickPaintedItem 整层逐帧重画文字路径。Qt 最低版本提升至 6.7，本机使用 6.11.2。

## 实现

- **模型**：新增 DanmakuLayout，负责排序、时间窗口、车道分配、在屏集合与文字排版。度量/呈现共用 QTextLayout，不再用默认字体度量、另一套 painter 字体绘制。
- **文字与字体**：Windows 首选 Microsoft YaHei，macOS 首选 PingFang SC；使用 Medium 字重、Qt 场景图 Outline 效果与 QtRendering。保留字体回退，正文与描边共同应用不透明度。本机确认苹方可解析。
- **节点复用**：文字入场时创建节点，稳定滚动只更新变换；离场释放，切片/seek/字号/尺寸变化重新布局；跨屏 DPR 和场景图失效后重建节点。Qt 管理底层字形资源，没有新写 OpenGL 图集或依赖私有 Qt 接口。
- **帧节奏**：以窗口 frameSwapped 的 GUI 队列回调驱动下一帧，取代固定 16ms QTimer。空屏时只等待下一入场时刻；暂停、隐藏、禁用、0% 区域或无完整车道时停止连续帧调度。
- **媒体时间**：保留单调时钟插值；小幅解码器时钟回校平滑收敛，避免每次 100ms 轮询重建/倒退。显式 seek 立即使用目标时间，包括小于 0.5 秒的拖动。
- **密度保护**：最多 128 车道、256 个在屏项、每帧 64 次文字准备。超预算的已到期条目跳过，不积压到之后播放；超长异常消息最多处理 1024 个 UTF-16 单元。普通车道拥挤仍按原规则跳过，顶部/底部/滚动三模式保持。
- **截图**：顶部按钮调用 mpv 异步 `screenshot-to-file … video`，输出纯视频帧；不改变播放状态，不隐藏弹幕等待时机。按 COMMAND_REPLY 返回状态确认，再检查文件；移除固定 300ms 猜测，连续截图使用独立毫秒时间戳文件名。

没有更改 mpv 视频 FBO 的方向、API 请求和已通过手测的播放器控制面板。FluentUI 继续负责界面控件，弹幕属于视频绘制层，不适合逐条使用 UI widget。

### 本机非交互性能记录

场景图测试：1920×1080 逻辑画布、32 条 20px 中英混合弹幕，20 帧预热 + 200 帧计时；DPR 2 为 3840×2160 物理目标。完整测试包含模型推进、polish/sync/render；GPU 项记录 **CPU 提交时间，不是 GPU 完成或屏幕显示帧时间**。

| 后端 | DPR 1 中位 / P95 | DPR 2 中位 / P95 |
|---|---:|---:|
| 软件场景图 | 0.864 / 0.903 ms | 1.855 / 1.971 ms |
| OpenGL 场景图 | 0.150 / 0.174 ms | 0.346 / 0.478 ms |

两种后端连续 200 帧均验证文字节点创建计数不增长。2 万条同时间弹幕的模型入场样本约 0.15ms；绝大部分因车道占用被跳过。不得将这些数值当成任意密度的首次字形上传成本。

旧评估中的 QPainter 微基准与本次字体、字号、实际排版/节点流程不同，不计算简单倍数加速。尚未获得用户卡顿视频样本；真实视频解码、GPU 完成时间、垂直同步与跨显示器体验交由手测，未宣称 120Hz 整机验收通过。

## 手测清单

1. **密集播放**：使用之前明显卡顿的视频，开/关弹幕比较，普通窗口与全屏各试一次；观察连续滚动和新弹幕集中入场是否卡顿。
2. **字体**：macOS 苹方、Windows 微软雅黑；中文/英文/符号/emoji，浅色和深色视频画面。重点看字体粗细、细描边、圆弧边缘及首行/底行裁切。
3. **时间同步**：暂停 10 秒再继续、0.5/1/2/3 倍速、来回拖动（含小幅拖动）、切视频与番剧选集。不能残留旧片弹幕、明显倒退或暂停后跳跃。
4. **缩放与资源**：最小窗口、全屏、播放列表折叠/展开；Retina 与外接屏之间移动，Windows 100/125/150/200% 缩放；重复开关播放器，检查清晰度与资源不持续累积。
5. **顶部截图**：暂停同一视频帧，开/关弹幕分别点击截图，对比保存文件应相同且无客户端弹幕/控件/可关闭字幕；连续多次截图均有独立文件，截图时播放不应明显停顿。视频源自带的烧录文字仍会保留。

此前用户报告的顶部截图“包含弹幕”未在当前源码链路复现；这次已明确纯帧契约，并用真实 mpv 校验字幕剥离，原场景仍请复测。Windows 未在本机编译或人工验收。
