# 页面搜索、卡片交互与稍后再看分页

日期：2026-09-18。OpenSpec：`fix-page-card-search-and-pagination`。

## 本次修改

| 范围 | 修复后的行为 |
| --- | --- |
| 特别关注 → 专栏 | 空态从 Flickable 内容项移到可见视口，避免空内容只有 1px 高时文字中心越过上边缘。投稿、合集共用空态也按剩余视口定位，长提示限宽换行。 |
| 视频卡片 | 点击非封面区域调用原播放窗口入口；右键删除“在新窗口播放”，保留“打开链接”。普通视频与 PGC 均沿用原定位、续播及单实例播放管线。封面点击仍只预览，非视频条目仍可打开网页；失效视频不触发播放。 |
| 主窗口搜索 | Enter/Return 接入 FluentUI 的 `commit` 信号，同时处理失焦；输入与清空仅改变草稿。框外按下通过被动 TapHandler 移走焦点，保留原按钮和滚动事件。已失焦时点击清除会重新聚焦，随后 Enter/失焦提交空词。 |
| 搜索作用域 | 六个已接线卡片页各自持有 `searchQuery`；切页先提交旧页草稿，再恢复目标页关键词。设置页不显示搜索框。特别关注的三个分块仍共用该页面的关键词。 |
| 稍后再看 | 接口仍一次拉取全量数据，本地先搜索全量池，再按每页 30 条展示；底部分页含首页、末页、前后页和计数。翻页回顶，搜索词变化回首页；刷新后原页仍有效则保留，否则回到新的末页；刷新失败保留旧数据。空态也改为视口定位。 |

## 手测清单

1. 特别关注选择无专栏 UP，切投稿/合集/专栏，再缩窄窗口或展开导航；确认空态处于内容区，不越过上沿、不压住筛选和底部分页。输入不匹配词检查长空态。
2. 在动态、本地历史、在线历史、稍后再看及特别关注投稿/展开合集中，点击视频文字区域应直接播放；封面只预览，右键只有打开链接。检查普通视频、多 P 历史与 PGC 定位；失效条目不得起播，专栏/文集仍打开网页。
3. 输入文字时列表不变化；分别按 Enter、数字键盘 Enter、Tab、点击空白/按钮提交。提交后失焦，再直接点清除，随后点框外应恢复列表。
4. 动态搜索 A、稍后再看搜索 B，来回切换应分别恢复 A/B；在未提交草稿时切页，草稿只归旧页；经过设置页再回来仍保持。特别关注切三个分块使用该页自己的词。
5. 稍后再看超过 30 条时检查首/中/末页、边界按钮、计数与回顶；搜索仅出现在其他页的标题/UP 主也应匹配，结果从第一页展示；清空提交恢复全量分页。
6. 稍后再看末页刷新，列表缩短后页码应有效；断网刷新应保留原页旧数据，切去其他页面再返回应保留关键词、页码与列表。
