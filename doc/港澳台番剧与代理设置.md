## 使用方式

1. 在设置展开“代理设置”，默认 HTTP、localhost、7897，适用于本机 Clash 混合端口；也支持 SOCKS5 或不使用代理。
2. 如代理要求认证，可填写用户名/密码。用户确认原需求“加密”指认证；密码仅本次运行保留，重启需重新输入，其他配置持久化。修改后点击保存，错误输入不会部分覆盖原设置。
3. 在番剧页进入“港澳台”，首次完整扫描已追番全部页，匹配“（僅限港澳台地區）”及简体/括号变体，去重后每页 30 条；搜索对全部地区结果生效再分页。普通四档不重复显示这些作品。
4. 点击卡片或详情分集正常起播。Clash 规则必须令 B 站 API 使用合适地区出口；本机测试在用户切换全局转发后成功，程序没有更改 Clash 配置或系统代理。

## 请求范围

| 请求 | 路由 |
| --- | --- |
| 扫描账号已追番、普通页面/普通番剧 API | 显式直连 |
| 港澳台剧集详情、PGC DASH/durl 解析、候选失败回退、切集/清晰度解析 | 使用当前区域代理配置快照 |
| libmpv 视频和音频 | 显式直连，不继承模块代理或进程代理环境变量 |
| 弹幕与播放心跳 | 原有直连 API 客户端 |

每个区域任务拥有独立、不可变的网络客户端，代理用户名/密码不会进入播放器网络选项，也不设置应用级代理。修改配置使区域详情缓存失效，旧请求不能覆盖新配置下的详情；一次在途解析及其失败回退保持同一快照，下一次播放/换清晰度读取新设置。会员/试看权益检查保持原逻辑。

## 指定用例验证

[md28233436](https://www.bilibili.com/bangumi/media/md28233436/) 对应 season 37757，《進擊的巨人 The Final Season（僅限港澳台地區）》。仅执行只读请求，没有写入追番或发送观看心跳。

- 初始规则分流时，直连及 HTTP localhost:7897 的剧集详情返回 -404，播放 API 返回 -10403“所在地区不可观看”。
- 实际项目扫描已追番列表，确认能找到指定用例的港澳台版本（未打印其他关注内容）。
- 用户调整 Clash 后，同一入口的详情成功返回 16 集；实际项目 Qt 网络客户端与 PlayerApi 解析返回 15 个视频候选、3 个音频候选，is_preview=false。
- 从代理 API 获取地址后，对音频和视频分别执行显式直连的 1 KiB 范围请求，两者均返回 HTTP 206 / 1024 字节。签名地址仅在进程内使用，没有打印或持久化。
- 上述证明 API 代理与媒体直连的网络链路可用，不代替窗口内连续音画播放的手测。
