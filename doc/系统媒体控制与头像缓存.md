## 本轮行为

- 动态页刷新按钮位于标题文字右侧，间隔 12px；加载指示在按钮后方，显隐时不移动按钮，两者在 56px 标题带内垂直居中；下方分类独立折行。
- 特别关注页头像条与管理弹层按 UP mid 共用本地头像缓存，保存在应用数据目录 `avatar-cache/`。成功下载后的七天内直接使用本地图片；到期按需后台更新，持续打开的页面每小时检查有效期。失败保留旧图并退避五分钟再重试，同一头像并发请求合并。
- 缓存更新使用页面已知的最新头像 URL，不额外调用用户资料接口。图片验证后原子写入，成功时间保存在 PNG 中；独立图片请求不使用 B 站凭据。
- 特别关注默认头像使用用户提供的 `app/resources/images/noface.jpg`（Qt 资源 `qrc:/images/noface.jpg`）；头像源为空、加载中或错误时统一显示，原图保持不变，下载和缓存机制未调整。
- macOS 媒体中心发布当前视频封面，异步下载和后台解码，切播/关闭清除旧图并使旧回应失效；普通进度更新不重复下载。番剧优先使用单集封面，缺失时使用整季封面。
- 播放器接入 macOS 系统正在播放和远程命令，以及 Windows 系统媒体传输控件（SMTC）。媒体信息和命令与现有播放器同步。

## 手测清单

1. 动态页：刷新图标位于标题文字右侧；窄窗、亮暗主题下不挤入分类行。刷新时显示加载环，分类保持，旧卡片保留至响应成功。
2. 特别关注：首次显示头像后关闭并重启应用，应能复用本地缓存；管理弹层同一用户头像一致。断网后已有头像仍能显示；缺失头像或首次下载失败时显示所提供的 noface 图片，头像条与管理弹层一致。测试缓存到期仅操作隔离测试目录，勿修改真实数据。
3. macOS：实际起播后打开控制中心的“正在播放”，核对当前视频封面、标题、时长与播放/暂停；系统媒体键、暂停/继续、拖动系统进度（面板支持时）、上一项/下一项与应用同步。单项列表边界按钮不可跳到无效索引。覆盖普通视频与番剧，快速切换时旧封面不得覆盖新视频；无封面/网络失败时保留文字控制，不能残留上个视频封面。
4. Windows：使用 MinGW 和 MSVC 对应 Qt 套件构建；实际起播后在系统媒体面板验证标题、状态、时间与媒体键。面板提供进度定位时验证拖动。
5. 两个平台：播放中切集、换清晰度、调倍速、缓冲、自然播完、加载失败、关闭窗口及快速重新打开；系统不得保留可操纵旧条目的会话，也不应影响其他应用后续接管媒体键。

系统界面可能因操作系统版本显示不同的按钮；离线自动回归不替代真实系统媒体面板与 GPU 播放手测。
