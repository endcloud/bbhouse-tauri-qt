# 标准播放器列表与光标显隐调整

日期：2026-09-18。已归档 change：`archive/2026-09-18-refine-player-controls-visibility`。用户于 2026-09-18 确认 test perfect，已同步主规格并归档。

## 已实现

- 普通视频播放列表折叠后宽度为 0，不再显示 40px 窄条、条目数或展开箭头；列表头部只保留定位当前播放项，手动展开/折叠统一使用底部控制面板的列表按钮。
- 监听实际全屏状态：进入和退出全屏都自动收起列表，底部按钮同步取消活动态；全屏内仍可手动展开，退出后不会恢复旧展开状态。窗口缩窄自动收起与番剧选集行为保留。
- 控制面板因无操作自动隐藏时，处于播放区的静止光标同步隐藏，取消独立 5 秒等待。指针移动或重新进入画面会恢复光标与控制面板；离开画面恢复光标。暂停、加载、缓冲、菜单、滑块与控件交互继续保护面板和光标。

直播仍保留已验收的独立窗口行为。本轮改动仅作用于标准视频播放器。

## 用户手测

1. 普通视频点击底部列表按钮收起：右侧完全消失，视频占满内容宽度；再点恢复内容、当前项高亮与定位入口。
2. 列表展开时分别使用底部全屏按钮和 F 进入全屏：列表收起、按钮活动态关闭。全屏内手动展开，再用 Esc、F 或全屏按钮退出，确认再次收起且恢复原窗口形态。
3. 正常播放时鼠标停在画面中央：约 3 秒控制面板与光标隐藏；移动后立即恢复。窗口模式与全屏模式各验证一次。
4. 指针停在列表、标题栏或窗口外时不隐藏；重新进入播放区域恢复。暂停、加载/缓冲、清晰度菜单、进度/音量拖动时面板和光标保持可见。
5. 普通视频与番剧分别确认快捷键、播放暂停、弹幕、选集及列表切播正常；窄窗口中仍能从底部按钮展开列表。
