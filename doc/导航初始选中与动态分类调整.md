## 本轮 UI 行为

- **启动导航**：启动通过 `FluNavigationView.setCurrentIndex(0)` 选中动态并调用既有 `tap` 路由。原先只执行 `visitPage`，没有设置导航控件的选中索引。内嵌 Qt6 FluentUI 的程序选中 API 现在支持仅连接 `tap`、没有 `url` 的页面项，同步主列表/页脚索引，并忽略非法索引、分隔项和禁用项。
- **动态分类**：移除“全部”，保留视频、番剧影视、直播、专栏、动态、其他。首次启动、旧 `all` 设置或未知设置均回退视频；既有六档中的有效偏好仍恢复，控制器初值也改为视频。视频下的“全部分区”仍是分区筛选入口。
- **分隔线**：直播和专栏之间使用 FluentUI 主题色的竖向分隔线；分隔线与专栏按钮组成同一个布局项，窄窗时共同折行，不出现孤立分隔线。
