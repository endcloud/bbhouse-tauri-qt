# 内存优化修复与杜比用例验证

日期：2026-09-21。基线 `e9e41c3`，根据用户“按照结论修复”实施。页面修复继续使用 `optimize-memory-footprint`；媒体修复使用 `reduce-player-memory-churn`。两个 change 均等待用户手测，不归档。

## 已修复

1. 流行、直播接通控制器搜索/页码/滚动记忆；初始化回显不再触发回首页。番剧、稍后再看初始化分页控件至真实数据页码。修正特别关注、番剧、稍后再看调用未暴露给 QML 的普通 setter，改用可写属性。
2. 在线历史在模型、卡片高度布局后恢复稳定条目身份及行内偏移；动态同样恢复身份锚点，列数改变仍定位相同条目附近。池头部裁剪后保留可见条目；锚点本身被淘汰时落在现存窗口起点。
3. 动态池按首次追加次序淘汰，发布时间只负责展示排序；去重分组、待补查队列同步清理。新增发布时间递减的35页回归，超过2000条仍保留新加载旧动态。热门池上限仅针对综合热门，不截断完整榜单。
4. 在线/动态少量非空匹配不足一屏时有限续载，最多5轮，失败停止自动重试；用户主动续载保留既有游标，不强制重拉首页。
5. 下载页由主窗口保存标签、搜索、页码和滚动状态；未登录首次默认媒体库不覆盖以后的用户选择。关于页保存滚动。只保存轻量状态，不持有卡片树。
6. SeasonCard 使用显示尺寸 × min(DPR, 2)，与 FluImage 原策略一致。原版本DPR>2覆盖反而增加内存，DPR≤2不存在新的解码收益。
7. 同内容换档复用已完成/正在加载的弹幕；切内容、关窗隔离旧结果，失败可重试。增加默认关闭的白名单内存诊断。字幕原本已复用，保留现有机制。

## 原四项测试失败排查

- `history-controller`：首次初始化失败后，本机 MinGW 的 once_flag 重试停滞；改用互斥锁与成功标志，异常释放锁，下一次请求可重试。测试失败时也不再继续对未初始化数据库写入造成二次崩溃。
- `preferences`：测试持续打开 INI 文件，阻止 Windows 原子替换；读取检查后及时关闭句柄。
- `popular-page`：离屏平台缺失 Qt 字体目录警告被计为测试失败；Windows 测试显式使用系统字体目录，仍保留运行期警告断言。
- `player-runtime`：当前libmpv新增curl后端在空http-proxy下读取环境代理。使用显式直连的libavformat路径；旧版无curl-enabled选项时兼容跳过。真实本地HTTP、音轨候选失败/超时/取消回归保留，不放宽断言。

## 真实杜比用例

已验证 **BV1omoHYzEST**：4K29.97 HEVC Main10、Dolby Vision Profile8/RPU、HLG基底。隔离OpenGL探针、禁缓存/无弹幕/无音轨，1080P→杜比→1080P的阶段末私有提交量为 **313.14→1679.23→313.41 MiB**，杜比峰值1733.50MiB。实际走d3d11va-copy。返回低档后回落，符合用户观察。

本轮消除重复弹幕工作，但**未消除杜比解码/渲染的主要内存台阶**。独立D3D11原生呈现探针降到峰值1209.83MiB，但未包含Qt覆盖层，不能直接作为产品后端替换；需另行设计合成、HDR、截图与窗口生命周期。完整证据及线程对照见[播放器实测](播放器换档内存修复与杜比实测.md)。这些PrivateUsage数字不是任务管理器活动私有工作集，不能与显存计数相加。

## 用户手测

- 每页设置非空搜索/筛选，分页到第3页或滚动至中部，切设置后返回；检查卡片、搜索、分页选中态一致；动态/在线在缩放和改变列数后检查锚点。
