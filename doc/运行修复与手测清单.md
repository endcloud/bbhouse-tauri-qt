## 手测要点

建议先使用 Release 产物；macOS 与 Windows 各执行一次核心播放及头像检查。

1. **原问题复测**：从原来报错的卡片右键播放，尤其是长 aid/cid 视频、BV1DyY26eEtr、BV1N1tC6zE7B。确认有画面、有声、时间增长，失败提示能区分 API 业务码、HTTP 和内核问题。
2. **播放入口**：本地历史、在线历史、动态、稍后再看、特别关注投稿/合集、番剧分别起播。多 P 历史应播放对应 cid；免费番剧不误弹会员提示；不可播内容仍准确报错。
3. **控制与续播**：暂停/继续、拖动、0.5x/2x/3x、音量、清晰度与编码换源；关闭后再打开恢复本地位置。切清晰度失败时旧流仍可继续，不能留下永久加载圈。
4. **状态边界**：起播未完成就切视频/关闭；连续开关播放器；剧集第 1 集切普通视频；连续点击不同列表项；失败后重选当前项。确认无旧音轨、旧弹幕、卡死或无法重试。
5. **头像**：特别关注头像条及管理弹层，明暗主题、选中/未选中；macOS Retina/外接显示器，Windows 100%/125%/150%/200%。重点观察圆边锯齿、黑边和切屏后清晰度。
6. **所有页面布局**：动态、本地历史、在线历史、稍后再看、番剧、特别关注、设置、播放器；展开/收起导航、最窄窗口、最大化、长标题/英文语言。检查工具行与正文不重叠，分页末行可见，滚动条不盖住文字，设置内容不贴边。
7. **特别关注与弹层**：投稿/合集/专栏切换，空结果、分页、管理搜索/保存；封面预览不超出窗口；管理弹窗按钮布局和上下内边距一致。
8. **弹幕**：暂停 10 秒后继续、跨段拖动、倍速、缩放/全屏、顶部/底部/滚动混合，检查首行完整、无暂停后跳跃；切片不残留旧片弹幕。
9. **运行环境**：Windows 缺 DLL 时应显示具体缺库诊断；补好库后重启。播放器 Cookie 错误后修正文件，重选同条目能重新解析。

反馈时请附：系统与显示缩放、页面/内容标识、操作步骤、错误文案和期望结果；不要附 Cookie 或完整带签名的播放 URL。

## 已知边界

- Windows 未在本机编译或运行；macOS 输出为依赖本机 Qt/Homebrew 的开发程序，尚未做独立签名应用包。
- XML 弹幕不是历史全量弹幕；高级弹幕、CC 字幕与相邻预解析等既有增强需求未新增。
- 原交付时视频候选有回退、音频只用首候选；2026-09-19 已补音频逐候选异步回退与统一 CDN 优先级，见 [后续修复](Windows任务注册与CDN优先级修复.md)。
- QQuickFramebufferObject 使用 OpenGL。跨平台 GPU、硬解、DASH 音画和屏幕缩放以手测为准；低层回归不替代这些检查。
