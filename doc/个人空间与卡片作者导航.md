## 行为

- 动态、稍后再看、本地/在线历史的视频卡片支持点击 UP 主行进入个人空间。悬停/按下/键盘焦点有主题高亮，光标变手型，Enter/Space 可激活；点击不触发视频播放或封面预览。特别关注页保留原交互，无有效 UID 的行保持普通文字。
- 个人空间参考用户附图，以 FluentUI 实现资料头（返回、圆头像、昵称、UID、投稿数、特别关注、刷新）及圆角内容框。默认头像沿用项目内嵌 noface。资料加载失败保留入口昵称/头像，显示错误，可刷新。
- 投稿支持分区、最新发布/最多播放/最多收藏排序、服务端每页 30 条；合集每页 20 条，可展开视频/播放整个合集；专栏文集全量加载后每页 30 条本地分页。
- “播放本页”播放当前页搜索筛选后的投稿，避免无提示拉取整个创作者历史。单视频仍通过主体点击播放，封面点击预览。
- 内容区返回按钮或 Alt+Left 返回来源页。来源实例常驻，搜索、筛选、页码、滚动保持；点击左侧导航直接退出空间。标题栏搜索在空间独立管理，Enter/失焦提交。
- 空间浏览使用独立控制器，不影响特别关注当前 UP。设为/取消特别关注操作本地 JSON 快照，合并已有名单后原子保存；不发送云端关注请求，特别关注页同步更新。
- 在途请求切 UP、分区和排序时保存最新待处理请求，旧响应不污染当前身份；资料异步任务与页面生命周期隔离。

## 实现索引

- `app/qml/controls/HistoryCard.qml`：作者行入口；历史/稍后作者头像从已存 rawJson 恢复，无数据库迁移。
- `app/qml/MainWindow.qml`：缓存来源页面与个人空间二级路由。
- `app/qml/pages/UserSpacePage.qml`：资料头；参数化 `SpecialFollowPage.qml` 复用三档内容。
- `app/controllers/UserSpaceController.*` / `app/core/UserProfileApi.*`：独立资料与内容状态。
- `SpecialFollowController`：本地关注保存队列，避免首次未读文件或管理弹层并发保存丢成员。

## 手测清单

1. 在动态、稍后再看、在线/本地历史中检查 UP 行悬停/按下/焦点与手型；点击只进入该 UP 的空间。特别关注页的卡片 UP 行维持原交互。
2. 核对头像、昵称、UID、投稿总数；缺少头像显示默认图，网络失败有提示并可刷新。
3. 投稿切分区、排序、翻页、搜索；“播放本页”仅播放当前筛选列表；封面预览和单视频播放正常。合集展开、返回合集列表、批量播放，以及专栏链接正常。
4. 在有搜索词、筛选和滚动的位置进入空间；更改空间搜索后返回，来源状态不变。改从另一来源/另一 UP 进入，确认无串页、旧作者或旧搜索残留。
5. 设为特别关注后进入特别关注页，确认新增成员且原有成员不丢；取消后同步移除。重启确认持久化。
6. 明暗主题、展开/折叠侧栏、最小窗口、长昵称和英文界面下，资料头按钮、页签、筛选和分页无覆盖。
