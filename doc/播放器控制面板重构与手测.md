## 界面与功能对照

| 区域 | 当前实现 |
|---|---|
| 顶部 | 返回、可省略长标题、截图、关闭，深色渐变 |
| 进度 | 全宽红色细轨道、悬停圆柄/时间提示、拖动 200ms 节流和释放精确定位 |
| 左下 | 播放/暂停、下一项（有下一项时）、静音及悬停展开音量、当前/总时长 |
| 右下 | 弹幕开关、倍速、清晰度与编码菜单、选集或播放列表、全屏 |
| 菜单 | 深色圆角向上展开，当前项标记红色，超高可滚动；分集列表虚拟化 |
| 右侧列表 | 保留定位当前项、切换、折叠/展开；深色背景与红色当前项 |
| 窄窗口 | 视频控制区不足 760px 时操作组分两行；窗口缩到 1080px 以下自动收起列表，仍可手动展开 |
| 显隐 | 播放时约 3 秒隐藏；离场约 600ms；暂停、加载/缓冲、菜单、拖动、悬停及键盘聚焦时常驻 |
| 光标 | 无交互时画面区静止 5 秒隐藏；移动、离场或暂停恢复 |

复用 `FluIconButton`、`FluSlider`、`FluMenu`、`FluMenuItem`、`FluTooltip`、`FluScrollBar` 和 `FluText`，通过本地包装调整颜色、轨道和内容布局。新增组件位于 `app/qml/controls/PlayerControls.qml` 与 `PlayerControlButton.qml`，无需修改 FluentUI 全局风格。

保留七档倍速（0.5/0.75/1/1.25/1.5/2/3）与保持速度、H.264/H.265/AV1、会员和不可用档位提示、弹幕、截图、选集、列表、全屏及原快捷键。增加 M 静音/恢复、Shift+N 下一项。Space 播放/暂停，左右方向键 ±5 秒，上下方向键 ±5 音量，F 全屏、Esc 退出全屏，D 弹幕。

已补齐新控件的英语翻译。未新增后端尚未提供的字幕、画中画或缓冲百分比入口。

## 手测清单

1. **布局**：普通视频与番剧、最小窗口/最大化/全屏，展开和折叠列表；检查进度位于按钮上方、窄窗两行无重叠，长标题及长清晰度名称不溢出。中文/英文、明暗主题各看一次。
2. **显隐**：播放时指针停在画面中央，约 3 秒面板隐藏、5 秒光标隐藏；移动恢复。暂停、加载、悬停按钮、打开菜单、拖动滑块时不隐藏；从控制区移到列表或窗外后应快速隐藏。
3. **进度**：悬停显示对应时间；点击、缓慢拖动、快速跨段拖动后音画与弹幕定位一致；释放后将鼠标移回画面，确认面板恢复自动隐藏。无时长/不可定位状态不能拖动。
4. **音量**：悬停展开、拖动调整；点击图标或 M 静音，再次操作恢复静音前音量。Tab 到音量图标能继续进入滑块，键盘调节后状态同步。
5. **菜单**：全部倍速、保持速度、清晰度和三种编码；当前项标记更新、不可用档位无法选中，菜单不会超窗或穿透触发暂停。Esc 和点击外部关闭后快捷键恢复。
6. **选集与列表**：长分集列表滚动、打开定位当前项、上下键和 Enter/Space 确认；普通视频下一项/Shift+N、列表切换和定位当前项、折叠与展开。最后一项不显示下一项按钮。
7. **原功能回归**：截图、弹幕 D、播放/暂停 Space、方向键、F/Esc、返回与关闭；全屏退出恢复此前窗口状态；再次打开正常续播，无残留声音。确认画面方向仍正确。

反馈建议包含：系统/显示缩放、窗口状态、内容类型、具体操作及截图。无需提供 Cookie 或签名媒体地址。
