# 直播页面与原生播放交付

日期：2026-09-18。已归档 change：`archive/2026-09-18-add-live-page`。用户已确认本次先完成列表和播放，不纳入实时弹幕。首版及控制面板、导航调整均经用户手测 pass，已于 2026-09-18 同步主规格并归档。

## 已实现

- 主导航新增“直播”，首次进入加载，切页返回保持列表、搜索和滚动。关注开播卡片显示封面、标题、主播、分区、人气；点击封面/标题播放，主播名进入个人空间。
- 登录凭据沿用 `bilibili.cookie.txt`。关注接口每页最多 10 人，按服务端分页信息续载，只显示 `live_status=1`，跨页去重。过滤后空页自动继续，单次最多扫描 100 页；加载更多显式触发，搜索仅筛选已加载房间并有范围提示。
- 刷新保留旧卡片直到新结果成功；失败/未登录、无人开播及搜索无匹配分别显示。加载状态不清空旧列表；每次刷新/续载使用同一 Cookie 快照，过期回应无法覆盖新状态。
- 独立直播播放器复用 libmpv，优先 AVC HTTP-FLV，再回退兼容的 HLS/HEVC 及 CDN。菜单显示接口真实返回的清晰度，选择清晰度会重新取流。支持暂停/继续、音量、静音、重新连接/回到直播、浏览器打开、双击或 F 全屏、Esc 退出全屏、空格暂停。
- 直播无点播进度条、seek、续播、历史写入、观看心跳、XML 弹幕或自动下一集。直播会话与点播控制器独立，互不改写设置。
- 起播 12 秒无响应或播放缓冲 20 秒时尝试下一候选；候选遍历一次后停止并提示重新连接。流结束/中断提示重连以重新确认房间状态，轮播/未开播/被锁定/未验证密码明确拒绝。
- 快速换房、换清晰度、重连和关闭使用请求代数隔离；关闭停止内核及计时器并解除视频挂载。
- API 与媒体显式直连，媒体仅设置直播 Referer/UA，不注入 Cookie、区域代理凭据。签名 URL 仅在内存使用。中英界面文案均已补齐。

参考与选型、端点字段、DPlayer/Tauri/wiliwili 对照见 [直播接口与内核调研](直播接口与内核调研.md)。本次无需新增依赖，参考仓库只读。

## 手测清单

1. 导航进入直播：确认关注中的当前开播房间、封面、标题、主播、分区；加载更多不重复；刷新和无人开播/登录失效状态正确。
2. 搜索标题或主播后切其他页再返回；进入主播空间再返回，搜索与滚动应保留。没有匹配时仍可加载更多。
3. 点击卡片，确认实际窗口有画面、有声、方向正确，连续播放稳定；同一窗口切不同直播间，不能串房或残留旧音频。
4. 切清晰度，核对当前标签与实际返回一致；暂停后继续，重新连接返回最新直播画面；音量和静音、浏览器打开正常。
5. 播放中断网/恢复：应有限回退，失败后可重连；主播下播显示结束提示；反复开关窗口、解析中立即关闭不崩溃、不后台出声。
6. F/双击全屏、Esc 返回、空格暂停；最小窗口、最大化、中文/English、明暗主题和高 DPI 下控件不重叠。
7. 已配置港澳台代理时直播仍直连；再播放普通视频/番剧，原点播进度、弹幕和清晰度行为不受影响。

本次未实现直播 WebSocket 弹幕、聊天/礼物/SC、录制或轮播。Windows 完整构建运行和 GPU/连续直播观感需要对应环境手测。用户已确认 pass，`add-live-page` 已同步归档。
