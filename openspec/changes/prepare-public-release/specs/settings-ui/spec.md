## MODIFIED Requirements

### Requirement: 播放与弹幕显示设置

设置页 SHALL 保留弹幕实现选择，并使用 FluentUI 提供默认弹幕状态、不透明度（0–100%）、字号（12–48 像素）、显示区域（顶部 1/4、半屏、全屏）、密度上限（不限、20、40、60、80、100 条同时在屏）和合并相似弹幕开关。偏好 SHALL 持久化且即时通知当前播放器，页面创建 MUST NOT 覆盖已保存值。弹幕开关 SHALL 与播放器按钮及 D 键同步，沿用记住最后状态的语义。

#### Scenario: 调整并重启

- **WHEN** 用户修改上述设置后重新进入设置页或重启应用
- **THEN** 控件与播放器恢复已保存的有效值，非法值回退或钳制到有效范围

#### Scenario: 播放器开关同步

- **WHEN** 用户在播放器中切换弹幕或在设置中修改默认弹幕状态
- **THEN** 两处状态同步并保存，视频播放与暂停状态不变

#### Scenario: 窄窗口与本地化

- **WHEN** 用户缩窄设置页或切换英文语言
- **THEN** 控件与说明自适应换行，不越过卡片边界，所有新增文案可本地化

#### Scenario: 首次启动默认值

- **WHEN** 相应弹幕偏好尚未保存
- **THEN** 默认开启、100% 不透明度、25px、顶部 1/4、密度不限、相似合并开启、预缓存图像实现；仅读取不写回配置

#### Scenario: 保留已有设置

- **WHEN** 用户已有合法偏好（包括旧版默认值）
- **THEN** 新默认值不迁移或覆盖用户保存值，配置内容保持不变

### Requirement: 二级代理设置

设置 MUST 提供可折叠“代理设置”区域，包含 HTTP/SOCKS5/关闭、host、1–65535 端口与可选用户名/密码认证；默认值 MUST 为 HTTP、localhost、7890。MUST 明示仅用于港澳台 API，媒体直连。保存 MUST 先整体校验，失败保留原配置。非秘密配置 MUST 持久化，密码 MUST 仅在本次运行内保存并明确标注。

#### Scenario: 配置本地 Clash
- **WHEN** 用户保存 HTTP、localhost、7890 且认证为空
- **THEN** 区域 API 使用无认证的本地 HTTP 代理，其他 API 与媒体保持直连

#### Scenario: 无效配置
- **WHEN** host 包含 URL 路径或端口越界
- **THEN** 设置提示错误且不部分覆盖已有配置
