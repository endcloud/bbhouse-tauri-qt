## Decisions

- 事件身份为 (video_key, view_at)，其中 video_key = business:oid:kid。新观看时间追加新行，相同时间忽略，不使用同步时间伪造播放时间。旧事件原始 JSON/进度不覆盖，展示元数据仅跟随最近真实观看事件，云端不再返回的旧视频不删除。
- 原生爬虫与手动同步共用；数据库页级事务、WAL、busy timeout 保留，新增数据库路径级 QLockFile 阻止手动/定时并行拉取；失败保留已提交页。
- 本地视频 badge 始终显示“已记录 · N 次”，悬停逐项列出真实记录；不污染在线历史等卡片的默认 badge。
- 本地瀑布流与在线历史视觉同构；本地数据保留 30 条分页及当前页搜索。服务管理独立窗口从此页入口打开。
- 后台初始化/读取/同步异常全部回投 GUI，不允许工作线程异常终止进程。服务写入后重入页面/手动刷新可读取新记录。

## Validation

使用项目 build 下临时 SQLite、离线历史 fixture；验证首次保存、重抓幂等、同视频多时间、旧事件保留、旧页不倒退、失败页事务、跨进程互斥与 GUI 异常。构建 Release/Debug、运行 CTest、OpenSpec 严格校验；UI 由用户手测，不访问或修改用户真实历史库。
