## MODIFIED Requirements

### Requirement: 标题栏与窗格布局协同

自定义标题栏 MUST NOT 遮挡或干扰窗格菜单项的命中；**窗格折叠开关 MUST 位于标题栏最左侧**（参考图中原返回按钮的位置）：NavigationView 内置折叠按钮 MUST 隐藏，由标题带内自绘按钮承担折叠/展开切换，标题栏 MUST NOT 提供返回按钮；个人空间等内容区二级页面 MUST 提供返回来源的按钮，返回 MUST 保留来源页面状态。窗格折叠按钮 MUST 处理 DoubleTapped 事件以阻止标题栏双击最大化手势的意外触发。窗格折叠按钮 MUST 在亮色/暗色两种模式下均显示适当的 hover 与 pressed 背景色。窗格折叠/展开时标题文字的水平位置 MUST 跟随窗格宽度偏移，MUST NOT 与窗格图标重叠。**主窗口左上角的应用标题与图标 MUST 被隐藏**（但保留在 XAML 中），以避免与搜索框在导航窗格展开时重叠。标题栏高度 MUST 从 40px 增至 48px，以保证搜索框与两侧元素协调。标题栏 MUST 支持嵌套卡片搜索框：搜索框 MAY 呈现于标题栏（依当前页面是否为呈现卡片的页面而定），搜索框 MUST 不遮挡折叠按钮与系统 caption 按钮的命中。标题栏拖拽行为 MUST 保持：非交互区可拖动窗口，系统 caption 按钮不受影响。系统 caption 按钮（"_ □ ×"）MUST 通过 DWM 属性在亮色/暗色模式下显示正确的图标颜色与 hover 背景。

#### Scenario: 折叠按钮可点且阻止双击最大化

- **WHEN** 用户快速双击标题栏最左的窗格折叠按钮
- **THEN** 窗格折叠生效，按钮自身不被标题栏拖拽区拦截，搜索框不遮挡该按钮，窗口 MUST NOT 触发最大化

#### Scenario: 折叠按钮 hover 效果在亮色/暗色模式下均生效

- **WHEN** 用户在亮色模式或暗色模式下将鼠标悬停在折叠按钮上
- **THEN** 按钮显示对应主题的 hover 背景色

#### Scenario: 标题与图标隐藏

- **WHEN** 窗格从折叠切换到展开
- **THEN** 应用标题与图标保持隐藏，不与搜索框重叠

#### Scenario: 标题随窗格偏移

- **WHEN** 窗格从展开切换到折叠窄轨
- **THEN** 标题文字左移至窄轨右侧，不与菜单图标重叠

#### Scenario: 无返回按钮

- **WHEN** 页面无二级层级时查看标题栏
- **THEN** 折叠按钮之外不出现返回按钮

#### Scenario: 搜索框居中且不遮挡

- **WHEN** 标题栏居中呈现搜索框
- **THEN** 搜索框水平垂直双向居中，标题栏高度 48px，折叠按钮与系统 caption 按钮仍可正常命中

#### Scenario: Caption 按钮主题适配

- **WHEN** 用户在亮色模式下查看窗口右上角系统按钮
- **THEN** 按钮显示黑色图标与浅色 hover 背景；暗色模式下显示白色图标与深色 hover 背景
