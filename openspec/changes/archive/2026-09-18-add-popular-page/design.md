## Context

Qt 使用 FluentUI、阻塞式 API 加线程池、常驻页面及统一 HistoryCard/PlayerController。Tauri popular 页是功能参考，API 文档是端点与载荷参考；不复制其中“留下”错名或缺期数参数的实现。

## Goals / Non-Goals

实现四档内容及所有参考排行榜分类，补全每周必看选期。复用现有封面预览、作者导航、原生 UGC/PGC 播放与独立页搜索。不新增浏览器播放器、下载、推荐算法或账户写操作。

## Decisions

- PopularApi 共用 BilibiliApiClient 与 WBI，接口显式直连。每周目录先加载，再将明确的 number 传给当期接口，按实际期号排序，展示服务端日期/名称；不按日期猜期数。
- PopularController 为每个页签/榜单/周刊期数保留会话快照，刷新失败不清空成功快照。后台任务捕获不可变选择和请求代数，晚到结果不能覆盖新选择。目录失败和内容失败分别显示与重试。
- 综合热门使用 pn/ps 服务端续载，按稳定视频键去重；其余完整榜单先本地搜索再按 30 条分页，避免同时实例化全部卡片。搜索不自动扫描远端内容。
- 榜单视频复用 HistoryCard；播放数/弹幕统计与观看次数分开，不伪造观看时间。PGC 有 seasonId 时经独立 BangumiController 取详情并调用 playSeason，无整季 ID 时使用 epId；UP UID 以字符串跨 QML 边界。
- 列表采用稳定 QML ListModel 与虚拟化 GridView，热门续载仅追加，忙碌/错误通知不重建卡片；完整榜单分页每次最多呈现 30 条。
- QML 冻结标题与筛选，期数选择器限制宽度，错误换行；沿用单层 24px 边距、FluentUI 滚动条和预览层。卡片采用动态页的 300px 列宽和 16px 列间距，整组居中；网格行高按已实例化卡片的最大实际高度加 16px 计算，同一选择只增高，切选择/分页/搜索或卡宽变化时重算。底部分页与数量标识合为一行，分页控件保留固有宽度以防内部 Flow 换行；排行榜选择器位于分类切换行最右侧，额外预留 12px 右边距。

- 下拉选项文字统一通过 `ComboBox.textAt(index)` 解析，避免委托自行区分 JS 数组、QVariantList 与 Qt 模型角色导致选项为空；显式声明委托 index，复用 FluentUI 的明暗文字颜色。离线页面回归实际展开两类菜单，并检查目录刷新后的标签和两种主题可读性。

## Risks / Trade-offs

榜单接口受登录、风控和服务端变动影响，保留真实错误且由用户重试；不将错误当作空榜单。节目、音乐及部分下架内容可能无可播稿件，不能拼凑虚假播放 ID。UI、GPU 播放和 Windows 需人工验证。

## Validation

离线 fixture 覆盖期目排序、参数、载荷、长 ID、PGC 和音乐回落；状态回归覆盖快速切换、晚到响应、刷新保旧、分页去重及重试。运行主程序与测试目标构建、CTest、隔离 QML 装载、OpenSpec 严格校验与 diff 检查。
