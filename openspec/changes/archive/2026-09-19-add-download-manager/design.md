## Context

现有 PlayerApi 提供 UGC/PGC DASH 候选和字幕轨；PlaybackEntry 恢复 64 位视频标识。各页面共用 HistoryCard，播放器统一持有 mpv 和弹幕引擎。现有数据目录和 BBHOUSE_DATA_DIR 支持测试隔离。

## Goals / Non-Goals

目标：可选择视频（含音频）、仅音频、弹幕和字幕；持久化任务及基础资料；串行可靠执行、取消和重试；完成媒体可校验播放；导入文件不复制，只有移除确认中明确勾选删除物理文件才删除源文件。

本次不实现直播录制、会员/地区限制绕过、整季批量下载、全历史弹幕补齐或自动分发外部工具。下载同当前卡片分 P/分集对应，未指明分 P 时沿用首 P 定位。

## Decisions

1. 新增 downloads.sqlite，与历史库隔离。SQLite 是项目现有嵌入式文件数据库，不需要 SQL Server 服务。只持久化白名单元数据与路径，不落 Cookie、签名流 URL、原始 API JSON。
2. 任务在专用后台执行，串行处理限制带宽和资源；主线程接收进度。全部资源成功后清理本任务分轨与标记；取消或退出终止子进程，重启恢复为可重试状态，重试重新解析临时媒体 URL。
3. QProcess 参数数组启动工具，不调用 shell；aria2 输入通过标准输入传递，凭据与签名地址不进日志/数据库。所有媒体/附件显式直连；仅区域 PGC API 使用不可变代理快照。
4. 按用户确认，视频输出使用 MP4、纯音频使用 M4A，FFmpeg stream-copy 保留 DASH 编码，避免重编码。XML 与媒体同名，SRT 按语言区分。撞名使用时间戳，不覆盖已有文件。
5. 目录默认 QStandardPaths::DownloadLocation（Windows 对应用户下载目录）；允许文件夹选择。aria2/FFmpeg 可设置完整路径，工具缺失明确提示。
6. 媒体库刷新和起播前检查本地文件；不存在、空文件或不可读条目禁播。导入使用本地文件 URL，路径可含中文/空格，按规范路径去重。同名 XML 缺失静默跳过。
7. 本地播放分支在 Cookie/API 之前分流；不读写在线历史库、不上报心跳；mpv/弹幕时钟仍复用，本地会话从文件开头播放。字幕可作为本地外挂加载。

## Risks / Trade-offs

- 服务端权益、地区、风控和有无字幕仍由 API 决定，错误需可见，不伪造完成。
- 文件存在不等于编码受支持；最终解码由 mpv 判断，失败需反馈，不能跳去网络回落。
- 下载目录是用户文件，默认仅清理成功任务临时文件；移除记录时只有确认勾选删除物理文件才删除该记录关联文件。普通取消保留可重试分轨。
- 外部工具需本机安装或设置路径；发行打包暂不附带工具，依赖与许可在交付文档注明。

## Migration Plan

首次创建独立下载数据库，无历史库迁移。新偏好仅影响新任务；运行任务使用不可变配置。用户已于 2026-09-19 验收并要求同步归档；Windows 原生验证边界保留在交付文档后续清单。

## Validation

使用 build 内隔离数据库、媒体和假工具/本地 fixture 验证 SQL 持久化、进程参数、格式转换、失败/取消/重启、导入检测和本地播放器。构建 Release、全量 CTest、QML 非交互冒烟与 OpenSpec strict；不触碰用户数据库、真实观看记录或注册系统任务。

## 2026-09-19 用户反馈

下载对话框增加本次任务清晰度。视频/仅音频互斥，视频强制包含可用音轨；两项均关闭可下载附件。FFmpeg 合并在同目录临时文件执行，成功改名后供媒体库使用。全部所选附件完成后清理准确任务基名的 .video.m4s/.audio.m4s 及 .complete/.aria2，清理失败提示但保留成功媒体。该清理已获本次用户明确授权，覆盖用户下载目录。

## 本地视频起播与渲染握手

用户验收下载调整后反馈本地视频黑屏、有声音和时间轴。离屏真实 libmpv 实验证实：先加载 H.264/AAC，再创建渲染上下文会使视频轨禁用而音轨正常；反序可得到红色像素。`mpv/render.h` 的生命周期约束要求先创建 render context 再初始化视频。

MpvVideoItem 在 GL 渲染线程创建上下文成功后，排队向主线程发出就绪通知；每次客户端绑定变化增加版本号，过滤旧内核的就绪和错误通知。PlayerController 的本地及在线候选加载共用该门控：就绪前不提交 loadfile，也不启动候选超时；切播与关窗清除旧等待，恢复仅使用当前请求。已就绪内核的后续切播无需额外等待，不使用固定延迟，也不更改硬解配置。

音频及隐私回归以真实 libmpv 软件渲染上下文提供非图形环境的就绪条件；macOS 增加生产 MpvVideoItem 的离屏 OpenGL 像素验证，覆盖加载早于挂载、切播与重开。无真实用户媒体或数据库写入。

## 实时进度、封面与移除

aria2 的控制台输出在后台增量读取，仅保留有界缓冲并提取数值百分比，不日志化原始内容；实际百分比映射到资源阶段，解析/合并/附件使用不定进度。主线程只更新内存中的目标记录并发出 `taskProgress`，每卡片按 ID 更新进度，不触发整个 QVariantList 的重建。状态持久化在专用串行线程池排队，进度不写 SQL。

导入立即建记录，封面在独立串行线程池执行 FFmpeg，优先读取 attached_pic（含可识别的容器图片附件），无内嵌封面时回退首帧。只用本地输入协议，限时、限制图像大小，JPEG 缓存在应用数据目录，封面晚到不得复活被移除记录；原有导入记录启动后也补提取。

下载管理使用独立上下文菜单，仅包含“移除”。确认框每次重置不删除；勾选后仅删除准确关联媒体、XML/SRT 与分轨标记，不递归清空目录。活动下载先发取消并等进程结束，再以最终返回记录执行后台删除。文件删除失败保留记录并提示，共享文件拒绝删除。数据库保存/移除同一后台队列排序，防止晚到保存复活记录。UI 不执行进程等待或文件删除。

用户验收后追加专属目录清理：物理文件删除成功后，按记录的 basePath 校验父目录与文件基名相同且带 reserveBase 生成的时间戳后缀，仅对空目录执行一次 rmdir。导入记录明确跳过；不递归、不向上删除下载根目录、不删除仍含隐藏文件或其他内容的目录。目录权限导致清理失败沿用移除失败提示并保留记录供重试。
