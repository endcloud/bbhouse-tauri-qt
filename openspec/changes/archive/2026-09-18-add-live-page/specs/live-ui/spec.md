## ADDED Requirements

### Requirement: 关注开播列表

直播页 SHALL 使用登录凭据分页获取已关注且正在直播的房间，显示封面、标题、主播、分区及人气，房间和用户 ID MUST 以字符串跨 QML 边界。

#### Scenario: 分页与过滤
- **WHEN** 用户首次进入或加载下一页
- **THEN** 异步请求相应页，过滤未开播条目并按房间去重，存在后续页时提供加载更多入口。

#### Scenario: 刷新和失败
- **WHEN** 刷新失败或登录失效
- **THEN** 保留已有卡片，显示可重试错误，不将失败当作无人开播。

#### Scenario: 搜索已载房间
- **WHEN** 用户提交标题或主播搜索词
- **THEN** 本地筛选已加载条目，标明已加载范围，仍允许主动加载更多。

### Requirement: 独立原生直播播放

点击直播卡片 SHALL 打开或复用独立直播窗口，用 libmpv 播放服务端返回的 HTTP FLV/HLS 单流，并提供音量、播放暂停、清晰度、重新连接和全屏。直播 MUST NOT 使用点播续播、进度拖动或观看心跳。

#### Scenario: 服务端清晰度与线路
- **WHEN** 房间取流成功
- **THEN** 按真实可用清晰度展示，失败时有限回退到其他候选线路，最终失败显示重连入口。

#### Scenario: 房间已下播
- **WHEN** 房间不处于直播状态或播放流结束
- **THEN** 展示已下播或连接结束状态，停止加载指示，允许重新连接。

#### Scenario: 切房和关闭
- **WHEN** 用户快速切房或关闭窗口
- **THEN** 旧请求和旧播放事件不覆盖新会话，关闭后停止播放、超时与重试，解除视频挂载。

### Requirement: 直播请求隔离

直播 API 及媒体 SHALL 显式直连，API 使用当前 Cookie 快照，媒体使用直播 Referer/UA。签名 URL 和凭据 MUST NOT 输出日志或落盘。

#### Scenario: 已设置区域代理
- **WHEN** 用户同时配置港澳台番剧代理并打开直播
- **THEN** 直播继续直连且不向媒体注入区域代理凭据。

### Requirement: 直播覆盖控制面板

直播窗口 SHALL 与标准视频窗口一致，以顶部/底部半透明渐变覆盖层展示控制面板，视频铺满内容区，不为控制面板预留固定高度。正常播放无操作 3 秒后 SHALL 淡出面板，指针移动或键盘操作 SHALL 恢复面板；暂停、缓冲、加载、错误、菜单打开、拖动音量或控制面板悬停/键盘焦点时 MUST 保持可见。

#### Scenario: 无操作与恢复
- **WHEN** 正常播放中没有控制交互持续 3 秒
- **THEN** 上下覆盖面板淡出，中央画面仍可双击全屏，移动鼠标恢复控制面板。

#### Scenario: 控制交互期间
- **WHEN** 用户选择清晰度、拖动音量或使用键盘访问控制按钮
- **THEN** 面板保持显示，结束交互后重新计时；加载失败的中央提示与重连按钮不受面板隐藏影响。
