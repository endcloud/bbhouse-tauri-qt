## Context

原网络层使用单个 QNetworkAccessManager，番剧采用追番/追剧两桶服务端分页；播放器从 API 解析 DASH/durl，再由 libmpv 连接媒体服务器。

## Goals / Non-Goals

**Goals:** 只有港澳台番剧模块的详情和 PGC 播放地址 API 走指定代理；发现已追番所有页的区域标题；媒体直连；认证可选。
**Non-Goals:** 修改 Clash 节点、运行隧道、代理媒体、绕过会员或付费权益、解锁服务端不提供的内容。

## Decisions

- 港澳台标签首次进入通过直连扫描已追番 type=1 全页，筛选简繁文字/括号变体，seasonId 去重，本地每页 30 条；搜索对完整区域结果过滤后分页。常规四档排除该类内容并保留原分页。
- 区域详情和 PGC 播放解析使用明确 regional 标记；代理配置在 Qt 主线程读取为 QNetworkProxy 值快照，池线程构造独立不可变客户端。禁止 setApplicationProxy 或修改共享客户端的当前代理。
- 普通 B 站 API 明确 NoProxy，区域客户端仅作用详情和 PGC API；弹幕/心跳/头像等不继承其配置。libmpv 明确禁用代理并通过本地代理陷阱测试环境变量也不会接管媒体。
- 设置支持 HTTP/SOCKS5/关闭，默认 HTTP localhost:7897。用户名/密码为认证，不提供虚假的 TLS 开关。密码仅在本次运行保存，避免普通配置文件持久化秘密；其他字段整体校验后持久化。
- 代理配置改变清除区域详情缓存，旧配置在途结果不覆盖新配置。正在解析的一次播放使用其快照，后续重新播放/换清晰度读取新配置。

## Risks / Trade-offs

Clash 的规则或出口不一定指向港澳台；应用只能选择本地代理入口，不能保证其出口地区。媒体 CDN 可能检查请求 IP，届时遵守媒体直连要求并显示实际失败，不隐式改走代理。服务端地区、登录或会员错误保持原样。

## Migration Plan

作为新活动 change 实现、构建与非交互回归，交付手测。个人空间 change 尚未得到用户本轮 pass，保持活动状态。
