## MODIFIED Requirements

### Requirement: 工具栏与刷新按钮

页面顶部 MUST 提供冻结标题带：左侧大标题"动态"，文字右侧为仅图标刷新按钮与加载指示，二者垂直居中；刷新按钮 MUST 紧邻标题文字右侧，间隔 12px；加载指示 MUST 位于按钮之后，显隐 MUST NOT 改变刷新按钮位置。六档筛选按钮（直播与专栏之间有分隔线）MUST 位于标题带下方独立行，刷新按钮 MUST NOT 混入分类行或随分类折行。点击刷新 MUST 清空已加载列表、重置 offset、重新拉取首页，但 MUST 保持当前筛选档位不变。刷新过程中 MUST 展示加载指示器，MUST 保留既有列表不闪空白。

#### Scenario: 刷新清空重拉

- **WHEN** 用户已加载 100 条动态且点击刷新按钮
- **THEN** 页面清空列表、重置 offset、重新拉取首页并渲染，已加载的 100 条不再保留（但筛选档位保持）

#### Scenario: 刷新筛选保持

- **WHEN** 用户选中"视频"筛选后点击刷新
- **THEN** 重新拉取首页后"视频"筛选仍选中，瀑布流仅展示视频类卡片

#### Scenario: 刷新加载指示

- **WHEN** 用户点击刷新且网络响应耗时 2 秒
- **THEN** 页面展示加载指示器（转圈或进度环）且既有列表不闪空白，响应返回后新列表替换旧列表

#### Scenario: 标题文字右侧刷新

- **WHEN** 用户查看动态页并缩窄窗口
- **THEN** 刷新始终位于标题文字右侧，筛选按钮在其下方独立折行，加载环不挤动分类按钮
