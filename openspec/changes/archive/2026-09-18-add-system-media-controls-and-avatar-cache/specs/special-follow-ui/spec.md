## ADDED Requirements

### Requirement: 特别关注头像七天缓存

特别关注页及其管理弹层的头像 MUST 使用按用户 ID 区分的持久化本地缓存；最近一次成功下载后的七天内 MUST 复用缓存，跨切页与重启不重复下载。缓存过期后 MUST 异步更新，期间继续显示旧图；失败 MUST 保留旧图且不得将失败时间作为成功刷新时间。缺失缓存 MUST 按需下载。缓存下载 MUST 校验图片并原子写入，同一头像并发请求 MUST 合并，过期回应 MUST NOT 覆盖较新的数据。缓存 MUST 位于应用数据目录并遵守测试数据隔离。

#### Scenario: 七天内重用

- **WHEN** 用户重新打开特别关注页或应用且头像下载成功不足七天
- **THEN** 头像从本地加载，不重复下载相同用户头像

#### Scenario: 到期刷新和离线回退

- **WHEN** 头像缓存达到七天且页面需要显示头像
- **THEN** 后台更新头像，期间展示旧图，失败保留旧图，成功替换并重置七天有效期

#### Scenario: 管理弹层共享

- **WHEN** 页面和管理弹层同时显示同一用户
- **THEN** 二者共用缓存及请求，成功更新后的图像一致

### Requirement: 内嵌默认头像

特别关注头像条与管理弹层 MUST 使用项目内嵌的 `noface.jpg` 作为头像源缺失、加载中及加载错误时的占位图，沿用头像圆形裁剪。默认图片 MUST 随应用打包并离线可用；默认图 MUST NOT 写入用户头像缓存或改变七天有效期、下载与失败回退逻辑。已有有效缓存时 MUST 继续优先显示缓存。

#### Scenario: 无头像或加载失败

- **WHEN** 特别关注用户头像源为空、加载中或加载失败且无可用旧头像
- **THEN** 展示内嵌 noface 图片，后续头像加载成功后正常替换
