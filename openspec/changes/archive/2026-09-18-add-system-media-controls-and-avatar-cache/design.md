## Context

项目使用 Qt Quick 与动态 libmpv，原生系统媒体会话需要独立桥接。Windows 默认工具链包含 MinGW，不能只提供 MSVC 专用实现。头像目前通过 QML 网络图片加载。

## Goals / Non-Goals

目标：标题带刷新，跨启动七天头像复用，以及 macOS/Windows 系统播放控制。系统媒体命令复用播放器既有入口，关窗、失败与切播不得留下旧会话。
非目标：修改播放内核、后台下载整站头像、Linux 媒体协议或绕过服务端权限。

## Decisions

- 刷新与加载指示位于 56px 标题带内，刷新距标题文字右侧 12px，加载指示在按钮之后；筛选行只放分类按钮。
- 头像以稳定用户 ID 区分，保存在应用数据目录；刷新成功更新时间，七天内页面重建不重复下载。过期沿用旧图，网络失败保留缓存；异步请求合并并防止旧回应覆盖新头像。
- 使用平台桥接层隔离 Objective-C++/WinRT 与 Qt 播放器。Qt 主线程执行播放控制，原生回调跨线程安全转发，析构解除注册。
- 发布实际加载状态，解析失败或关闭时清除会话；可切项与可定位状态决定系统按钮能力。同步进度进行适度节流。
- 采用离线网络 fixture 与媒体状态/命令测试；平台系统界面由用户手测。本机仅能验证 macOS 构建，Windows 需明确记录未实机验证。

- 默认头像原图复制到 `app/resources/images/noface.jpg` 并编入 Qt 资源；特别关注头像条和管理弹层在无头像源、加载中、失败时显示该图，仍沿用圆形遮罩。只更换展示占位，不改缓存 TTL、请求与重试。
- macOS 封面通过独立异步下载接入 `MPMediaItemArtwork`。当前播放条目传递封面地址；切播或关闭立即丢弃旧封面，异步回应必须匹配当前会话，不能复活关闭的媒体信息。无封面或失败时继续保留文字与播放控制，不使用头像占位作为视频封面。

## Risks / Trade-offs

系统媒体界面的展现依赖 OS 版本与前台媒体仲裁。Windows API 必须兼容项目 MinGW/MSVC 套件；macOS 系统面板及硬件媒体键仍需真实会话手测。七天以最近一次成功获取时间计算，离线时允许继续显示过期头像。
