## MODIFIED Requirements

### Requirement: 瀑布流卡片布局

历史列表 MUST 以瀑布流布局展示：列宽固定 300px，列数随窗口宽度自适应，整体水平居中，不出现横向滚动。列表 MUST 采用虚拟化网格渲染：仅视口内及邻近缓冲区域的卡片保持为活动渲染项，滚出缓冲区的卡片 MUST 被回收，重新进入视口时 MUST 以相同内容重建，不得产生白块闪现或内容错位。同一批已渲染卡片的行高 MUST 统一取其中卡片实测的最大高度（随内容与窗口宽度变化重新测算），较矮卡片在其网格单元内顶部对齐、下方保留空白，不得裁切或拉伸卡片内容。

#### Scenario: 窗口加宽

- **WHEN** 用户把窗口从 720px 拉宽到 1400px
- **THEN** 列数从 2 列增加到 4 列，卡片整体居中，网格重新虚拟化渲染不产生错位

#### Scenario: 深度滚动虚拟化

- **WHEN** 用户在已加载多页的历史列表中连续向下滚动数千像素后再滚回顶部
- **THEN** 滚动全程无白块闪现，仅视口与缓冲区内的卡片为活动渲染项，滚回顶部时先前离屏的卡片以相同内容正确重建
