## MODIFIED Requirements

### Requirement: 页面导航与选中态

内容区 MUST 按选中菜单项切换页面，导航项选中态 MUST 与当前呈现页面保持同步。在后台保留阈值内离开再返回"本地历史"页时，浏览状态（当前页码与已加载列表）MUST 保持，MUST NOT 重置回第一页。本地历史页同步进行中切换到其他页面 MUST NOT 取消同步；同步完成后的状态文本在返回页面时 MUST 可见。

#### Scenario: 切换页面

- **WHEN** 用户从"本地历史"点击"稍后再看"
- **THEN** "稍后再看"导航项转为选中态，内容区替换为其页面

#### Scenario: 返回本地历史状态保持

- **WHEN** 用户从"本地历史"（第 3 页）切到"设置"并在保留阈值内切回"本地历史"
- **THEN** 浏览视图仍停在第 3 页，列表无需重新加载即呈现

#### Scenario: 同步进行中切换页面

- **WHEN** 本地历史页同步进行中，用户切到"设置"再切回
- **THEN** 同步未被取消，进度指示与状态文本继续反映同步进度直至完成

## ADDED Requirements

### Requirement: 后台页面限时回收

系统 SHALL 默认在一级页面及个人空间离开后 5 分钟销毁 QML 实例及可重建的浏览缓存。当前页 MUST NOT 被回收，重新进入 SHALL 重建页面并按需请求；超时后分页、搜索和滚动位置允许重置。下载、同步、独立播放器和持久化数据 MUST NOT 被页面回收中断或清除。

#### Scenario: 后台超时与返回
- **WHEN** 用户离开动态页超过设置阈值后返回
- **THEN** 旧页面及展示列表已释放，新页面重新加载，当前页不会因同一计时器再次销毁

#### Scenario: 短时往返
- **WHEN** 离开后在阈值内切回或重复选择当前页
- **THEN** 保留同一页面实例及其浏览状态

#### Scenario: 后台任务继续
- **WHEN** 下载管理或本地历史页在下载/同步期间超时
- **THEN** 任务继续执行，重建页面后显示当前任务状态
