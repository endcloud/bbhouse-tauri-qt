## Why

一级页面首访后永久保留 QML 对象及控制器列表缓存；异步任务、私有实现与底层句柄需明确所有权，避免长期使用增长及析构竞态。

## What Changes

- 默认后台页面保留 5 分钟，设置可选 1/5/10/30 分钟；到期卸载页面及浏览缓存，重新进入重新加载。
- 短时切回保留状态；当前页面不回收，下载/同步/播放器不受页面销毁影响。
- 审查应用及内嵌 FluentUI 指针、异步捕获、网络和原生资源释放，修复确认的问题。
- 按需释放播放器和浏览缓存，增加非交互生命周期回归与审计记录。

## Capabilities

### New Capabilities
- `memory-lifecycle`: 对象所有权、后台缓存释放及异步销毁安全。

### Modified Capabilities
- `app-navigation-shell`: 页面保留由永久改为有时限。
- `settings-ui`: 后台页面保留时间偏好。

## Impact

Qt/QML 页面宿主、浏览控制器、播放器、底层资源及对应离线测试。既有用户数据库/凭据保持原样。UI 与 Windows 原生行为待手测；本次不发布远程版本。
