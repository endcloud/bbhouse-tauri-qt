## Context

页面由主窗口 Loader 持有，控制器由 QApplication 持有。仅将 Loader.active 设为 false 无法释放 C++ 的会话数据。Qt 父子所有权用于 QObject，独占资源使用 RAII；后台捕获对象必须在成员销毁前结束。

## Decisions

- 引入可复用 ExpiringPageLoader，后台计时到期卸载；当前页面和重选不重建。切回重启下一次后台计时，阈值改动从改动时重新计时。
- 偏好为 1/5/10/30 分钟，默认 5；不提供无限保留。用户空间也使用同样生命周期，底层一级页离开后可回收。
- 失效回调同步清理对应控制器展示池，递增请求代际，阻止晚到响应重新填满缓存。保留下载任务、历史同步、特别关注名单和持久数据。
- 页面超时后搜索/滚动/分页临时状态可重置；后台同步结果仍由独立控制器保留。
- UP 会话、流行内容选择、番剧详情各采用最近使用顺序上限 12，头像元数据上限 512；在途任务仍可暂时持有独立快照，完成后释放。
- 不强制调用 QML GC、清空全局字体缓存或降低媒体缓冲，避免抖动和播放退化。内存回收不承诺 RSS 立刻同比下降。

## Validation

新增真实 Loader 非交互生命周期测试、偏好验证和控制器晚回应测试，构建 app 及全部 CTest；记录手测与跨平台边界。所有测试数据位于 build 并自动清理。
