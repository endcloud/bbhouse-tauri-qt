# settings-ui Specification

## Purpose
定义设置页的契约：冻结大标题与滚动内容分区、外观与行为（主题/语言）选择及生效语义、重新登录入口（关于信息由独立页面展示）、偏好持久化——作为"设置"菜单项的真实页面。

## Requirements

### Requirement: 页面结构与冻结标题

设置页顶部 MUST 呈现大标题"设置"（本地化）作为最顶层冻结区：内容滚动时标题保持固定不随滚动离开；标题带之下为可滚动内容区，与窗格右侧内容统一左对齐线。页面 MUST NOT 发起任何网络请求。

#### Scenario: 标题冻结

- **WHEN** 用户在设置页向下滚动内容
- **THEN** 顶部大标题保持可见且位置固定，仅下方内容滚动

#### Scenario: 无网络行为

- **WHEN** 用户进入设置页并操作各控件
- **THEN** 不发出任何网络请求

### Requirement: 外观与行为区

设置页 MUST 提供"外观与行为"区，含两个下拉框选择行（图标 + 主标签 + 说明文字 + 右端下拉框）：①主题设置（亮/暗/跟随系统）；②语言设置（简体中文/English/跟随系统）。两项默认值 MUST 均为"跟随系统"。

#### Scenario: 区块构成

- **WHEN** 用户打开设置页
- **THEN** 可见"外观与行为"分区标题与主题、语言两个选择行，两行当前值均为"跟随系统"

#### Scenario: 主题即时生效

- **WHEN** 用户把主题从"跟随系统"切到"暗"
- **THEN** 主窗口整体立即切换为暗色（后续新开窗口随之），当前值显示"暗"；切回"跟随系统"立即恢复系统外观

#### Scenario: 语言下次启动生效

- **WHEN** 用户把语言从"跟随系统"切到"English"并重启应用
- **THEN** 界面呈现英文资源；会话内变更时 MUST 显示需重启生效的本地化提示；切回"跟随系统"并重启后恢复系统语言解析

### Requirement: 偏好持久化

主题与语言偏好 MUST 持久化（应用数据本地设置），跨启动生效；未设置或设为"跟随系统"时行为 MUST 等同于变更前（主题跟随系统、语言按系统语言解析）。

#### Scenario: 跨启动保持

- **WHEN** 用户设置主题为"暗"、语言为"English"后重启应用
- **THEN** 启动即暗色外观与英文界面，设置页两行显示所选值

#### Scenario: 默认等同跟随系统

- **WHEN** 从未修改过偏好
- **THEN** 主题与语言表现与本变更前完全一致

### Requirement: 调试开关

设置页 SHALL 提供"调试"区（临时调试性质，文案明示）：含一个"非大会员 Cookie"开关行（图标 + 主标签 + 说明文字 + 右端 ToggleSwitch），默认关闭；开关状态 MUST 持久化（应用本地设置）并跨启动生效。开关开启时，应用内全部 API 入口（播放窗口的解析/弹幕/字幕/取流——含播放内核网络层、在线历史页的游标查询等）SHALL 统一改用仓库根目录 `bilibili.cookie.normal.txt`（普通账号 Cookie）——会员判定、PGC 权益与清晰度 VIP 档门控随之按该账号的服务端真实应答呈现；播放内核在创建时烘焙凭据，凭据源翻转后的下一次播放解析 SHALL 重建内核以携新凭据。该文件缺失或无效时 SHALL 回退主 Cookie 并在播放窗口以非阻塞提示说明（每次会话至多一次）。历史同步爬取与定时服务 SHALL 保持主凭据（防止两账号观看历史合并写入同一本地库）；设置页自身 MUST NOT 发起任何网络请求，MUST NOT 影响主题/语言等其他偏好。关闭开关后，下一次 API 请求 SHALL 恢复使用主 Cookie。

#### Scenario: 开关持久化

- **WHEN** 用户打开"非大会员 Cookie"开关后重启应用
- **THEN** 设置页该开关保持开启状态，播放窗口持续以普通账号凭据解析播放

#### Scenario: 凭据切换的服务端真实呈现

- **WHEN** 开关开启（bilibili.cookie.normal.txt 存在且有效），用户起播一部会员专享内容
- **THEN** 解析与内核取流均携普通账号凭据，会员判定、试看/付费阻断与清晰度 VIP 档门控均按该账号的服务端应答呈现

#### Scenario: 全入口统一凭据

- **WHEN** 开关开启后用户在主窗口刷新在线历史页
- **THEN** 在线历史游标请求亦使用 bilibili.cookie.normal.txt，呈现该账号的云端历史

#### Scenario: 文件缺失回退提示

- **WHEN** 开关开启但 bilibili.cookie.normal.txt 缺失或不含 SESSDATA
- **THEN** 播放窗口回退主 Cookie 并显示一次非阻塞警告，播放不因此失败

#### Scenario: 关闭后恢复主凭据

- **WHEN** 用户关闭开关后起播内容或打开清晰度菜单
- **THEN** 播放解析恢复使用主 Cookie，会员判定以主账号为准

### Requirement: 播放与弹幕显示设置

设置页 SHALL 保留弹幕实现选择，并使用 FluentUI 提供默认弹幕状态、不透明度（0–100%）、字号（12–48 像素）、显示区域（顶部 1/4、半屏、全屏）、密度上限（不限、20、40、60、80、100 条同时在屏）和合并相似弹幕开关。偏好 SHALL 持久化且即时通知当前播放器，页面创建 MUST NOT 覆盖已保存值。弹幕开关 SHALL 与播放器按钮及 D 键同步，沿用记住最后状态的语义。

#### Scenario: 调整并重启

- **WHEN** 用户修改上述设置后重新进入设置页或重启应用
- **THEN** 控件与播放器恢复已保存的有效值，非法值回退或钳制到有效范围

#### Scenario: 播放器开关同步

- **WHEN** 用户在播放器中切换弹幕或在设置中修改默认弹幕状态
- **THEN** 两处状态同步并保存，视频播放与暂停状态不变

#### Scenario: 窄窗口与本地化

- **WHEN** 用户缩窄设置页或切换英文语言
- **THEN** 控件与说明自适应换行，不越过卡片边界，所有新增文案可本地化

### Requirement: 二级代理设置

设置 MUST 提供可折叠“代理设置”区域，包含 HTTP/SOCKS5/关闭、host、1–65535 端口与可选用户名/密码认证；默认值 MUST 为 HTTP、localhost、7897。MUST 明示仅用于港澳台 API，媒体直连。保存 MUST 先整体校验，失败保留原配置。非秘密配置 MUST 持久化，密码 MUST 仅在本次运行内保存并明确标注。

#### Scenario: 配置本地 Clash
- **WHEN** 用户保存 HTTP、localhost、7897 且认证为空
- **THEN** 区域 API 使用无认证的本地 HTTP 代理，其他 API 与媒体保持直连

#### Scenario: 无效配置
- **WHEN** host 包含 URL 路径或端口越界
- **THEN** 设置提示错误且不部分覆盖已有配置

### Requirement: 设置末尾重新登录
设置页 SHALL 在选项列表末尾提供“重新登录”，点击 SHALL 进入与首次启动相同的初始化页面，成功前 SHALL 保留原 Cookie。

#### Scenario: 重新登录
- **WHEN** 用户点击设置末尾“重新登录”
- **THEN** 仅显示 Cookie 文件/文本导入入口及帮助，不显示扫码，不立即删除现有凭据。
