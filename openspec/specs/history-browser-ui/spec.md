# history-browser-ui Specification

## Purpose
定义 WinUI 客户端的浏览体验契约：离线优先的历史卡片瀑布流、卡片信息元素、分页导航、多次观看角标与 tooltip、封面原图预览与下载。

## Requirements

### Requirement: 离线优先加载

应用启动时 MUST 直接从本地缓存加载历史并渲染，不发起任何网络请求；状态栏 MUST 展示已载入的视频数与观看记录数。点击"刷新"仅重读本地缓存。

#### Scenario: 无网络启动
- **WHEN** 设备离线且本地已有缓存
- **THEN** 应用正常展示历史卡片，状态栏显示视频与观看记录计数

### Requirement: 瀑布流卡片布局

历史列表 MUST 以瀑布流（masonry）布局展示：列宽固定 300px，列数随窗口宽度自适应，卡片放入当前最短的列；列表整体水平居中，不出现横向滚动。

#### Scenario: 窗口加宽
- **WHEN** 用户把窗口从 720px 拉宽到 1400px
- **THEN** 列数从 2 列增加到 4 列，卡片仍按最短列原则排布且整体居中

### Requirement: 卡片信息元素

每张卡片 MUST 展示：封面图（含总时长角标与观看进度条）、标题（最多两行）、副标题（仅当与主标题不同时显示）、UP 主名（缺省为"未知作者"）、业务类型标签（视频/番剧影视/直播/专栏/文集，其他类型回退为角标文案）、最近观看时间，以及观看进度文本（有进度时）。

#### Scenario: 番剧卡片
- **WHEN** 某条目 business=pgc 且带 badge="国创"
- **THEN** 卡片显示"番剧/影视"类型标签、分集副标题、时长角标与进度条

### Requirement: 卡片跳转与封面预览互斥

有效 archive/pgc 视频卡片主体左键 MUST 调用统一新窗口播放入口；非视频卡片主体 MUST 保持用系统浏览器打开条目链接（live→直播间、article→cv 页，uri 优先）。右键菜单 MUST 保留打开链接并移除新窗口播放项。点击封面 MUST 只打开原图预览，不得触发播放或跳转；失效视频 MUST NOT 播放。

#### Scenario: 点击卡片打开视频

- **WHEN** 用户点击有效稿件视频卡片的文字区域
- **THEN** 现有播放窗口入口起播该视频，不唤起浏览器

#### Scenario: 点击封面不跳转

- **WHEN** 用户点击卡片封面
- **THEN** 打开封面预览，不发起播放或唤起浏览器

#### Scenario: 原链接仍可访问

- **WHEN** 用户右键卡片选择打开链接
- **THEN** 默认浏览器打开该条目原链接

### Requirement: 分页浏览

列表 MUST 按每页 30 个视频分页，提供首页/上一页/下一页/末页导航，并显示"第 x / y 页 · 显示 a-b 共 n 条"；翻到边界时对应按钮 MUST 禁用。

#### Scenario: 末页禁用
- **WHEN** 用户已位于最后一页
- **THEN**"下一页"与"末页"按钮禁用，"上一页"与"第一页"可用

### Requirement: 多次观看角标与 tooltip

某视频的观看次数大于 1 时，卡片封面右上角 MUST 显示"N 次"角标；悬停角标 MUST 以 tooltip 按时间倒序列出该视频全部观看时间点（"共 N 次观看：1. …"）。观看次数为 1 时 MUST NOT 显示角标。

#### Scenario: 三次观看的视频
- **WHEN** 用户悬停某 `view_count=3` 视频的"N 次"角标
- **THEN** tooltip 显示"共 3 次观看"及按时间倒序的三个时间点

### Requirement: 封面原图预览与下载

封面预览 MUST 请求去掉 CDN 转码后缀（`@…`）后的原图 URL；预览层 MUST 支持鼠标左键单击任意位置（遮罩或大图）退出，且 MUST NOT 再提供独立的关闭按钮；右键提供"下载原图到图片文件夹"，下载请求 MUST 携带 `Referer` 与浏览器 `User-Agent`，文件保存到系统图片目录的 `bilibili_cover` 子目录；成功与失败 MUST 通过 InfoBar 反馈实际保存路径或错误信息。打开与关闭预览 MUST 播放缩放过渡动画：打开时从被点击卡片封面的位置放大至全屏，关闭时缩回该卡片封面位置；动画不可用或启动失败时 MUST 直接显示/隐藏预览层，不得阻塞或改变上述交互行为。

#### Scenario: 预览取原图
- **WHEN** 封面 URL 为 `…/foo.jpg@468w_292h_1c.webp` 且用户点击封面
- **THEN** 预览加载 `…/foo.jpg`

#### Scenario: 左键单击大图关闭
- **WHEN** 预览已打开，用户左键单击大图本身
- **THEN** 预览关闭，无独立关闭按钮出现在预览层上

#### Scenario: 打开缩放动画
- **WHEN** 用户点击某卡片封面打开预览
- **THEN** 预览大图从该卡片封面的当前位置以缩放动画展开至全屏位置

#### Scenario: 关闭回缩动画
- **WHEN** 用户在预览中左键单击关闭
- **THEN** 大图以缩放动画缩回来源卡片封面的位置，随后预览层消失

#### Scenario: 下载封面成功
- **WHEN** 用户在预览中右键选择"下载原图到图片文件夹"且网络可用
- **THEN** 原图保存到 `图片\bilibili_cover\`，InfoBar 显示成功与保存路径

### Requirement: 封面缩略图 CDN 转码加载

卡片封面缩略图 MUST 通过 B 站图片 CDN 的转码后缀按需加载：先去掉库中 `CoverUrl` 已有的 `@…` 转码后缀，再拼接 `@{宽}w_{高}h_1c.avif`（1c 居中裁剪，格式 AVIF）。宽与高 MUST 等于封面容器的 DIP 尺寸乘以当前窗口 DPI 缩放并向上取整。转码图加载或解码失败时 MUST 回退加载库中原始 `CoverUrl`（仅回退一次，不得循环重试）。封面原图预览与下载原图的取图行为 MUST NOT 因缩略图转码而改变。

#### Scenario: 按容器物理尺寸请求转码图

- **WHEN** 封面容器以 300×169 DIP 渲染、系统 DPI 缩放为 150%（物理像素 450×254），库中封面 URL 为 `…/foo.jpg@468w_292h_1c.webp`
- **THEN** 卡片缩略图请求 `…/foo.jpg@450w_254h_1c.avif`

#### Scenario: AVIF 解码失败回退

- **WHEN** 设备缺少 AVIF 解码能力，转码缩略图加载失败
- **THEN** 该卡片回退加载库中原始 `CoverUrl`，封面不空白，且不再对转码 URL 重新发起请求

#### Scenario: 预览与下载仍取原图

- **WHEN** 缩略图以转码 URL 加载后，用户点击封面打开预览并选择"下载原图到图片文件夹"
- **THEN** 预览与下载均请求去后缀的原图 URL（如 `…/foo.jpg`），与转码缩略图无关

#### Scenario: DPI 缩放变化后重新取图

- **WHEN** 窗口从 100% DPI 缩放显示器拖到 200% 缩放显示器
- **THEN** 缩略图按新物理像素（600×338）重新生成转码 URL 并重新加载

### Requirement: 回到顶部

主窗口内容区右侧边缘偏下位置 MUST 提供圆形"回到顶部"浮动按钮。列表向下滚动离开顶部时按钮 MUST 显示，列表位于顶部（或未滚动）时 MUST 隐藏；点击按钮 MUST 将列表滚动位置恢复到顶部。按钮 MUST NOT 遮挡分页栏，预览层打开时 MUST 被预览遮罩覆盖。

#### Scenario: 下滚出现、回顶隐藏

- **WHEN** 用户把历史列表滚动到中部后停止
- **THEN** 右侧偏下出现"回到顶部"按钮；点击后列表回到顶部，按钮隐藏

#### Scenario: 顶部时不出

- **WHEN** 列表位于顶部或内容不足以滚动
- **THEN** 按钮不显示

#### Scenario: 预览层之上被覆盖

- **WHEN** 列表已下滚（按钮可见）且用户打开封面预览
- **THEN** 预览遮罩覆盖按钮，按钮不响应点击

### Requirement: 浏览视图宿主于本地历史页

既有历史浏览视图（工具栏、瀑布流卡片列表、分页栏、回到顶部按钮、封面预览层）MUST 整体迁移至导航外壳的"本地历史"页面承载；本规格其余需求描述的浏览行为在页面承载形态下 MUST 保持不变。

#### Scenario: 从导航进入浏览视图

- **WHEN** 用户在导航菜单选中"本地历史"
- **THEN** 内容区呈现历史浏览视图的全部既有元素（工具栏、瀑布流、分页栏、回顶按钮）且行为与本规格其余需求一致

#### Scenario: 浏览视图随页面让位

- **WHEN** 用户从"本地历史"切换到其他菜单项
- **THEN** 内容区显示目标页面，浏览视图不再可见；切回"本地历史"后浏览状态（当前页码与已加载列表）恢复

### Requirement: 标题或 UP 主名称搜索

本地历史页 MUST 接受主窗口标题栏搜索框提交的搜索词，并仅对**当前分页内已加载条目**的**标题或 UP 主名称**做不分大小写的子串匹配筛选展示，满足任一条件即显示；搜索 MUST NOT 改变同步、翻页、回顶或封面预览行为，MUST NOT 发起网络请求，MUST NOT 跨分页搜索未加载条目，MUST NOT 改变本地数据库与同步口径。提交空词 MUST 恢复展示当前分页全部条目的原始顺序。搜索词与分页状态均为页面帧缓存的一部分：切页再返回时筛选效果与所在分页 MUST 保持。

#### Scenario: 当前分页筛选（标题或 UP 主匹配）

- **WHEN** 用户在本地历史页第 2 页提交关键词"算法"
- **THEN** 仅渲染第 2 页已加载且标题或 UP 主名称含"算法"的条目，其余条目隐藏，不发起网络请求

#### Scenario: 不跨分页搜索

- **WHEN** 用户在本地历史页第 2 页提交仅匹配第 1 页条目的关键词
- **THEN** 当前页无匹配条目（空态），页面不跳转到第 1 页、不跨分页搜索

#### Scenario: 清空恢复当前分页

- **WHEN** 用户提交空关键词或清空搜索框后提交
- **THEN** 当前分页恢复展示该页全部条目，顺序与未搜索前一致

#### Scenario: 翻页后保留搜索

- **WHEN** 用户在第 2 页提交关键词"算法"后翻到第 3 页
- **THEN** 第 3 页的条目按同一关键词筛选展示（标题或 UP 主名称），搜索词不丢失

#### Scenario: 切页返回状态保持

- **WHEN** 用户在第 2 页提交关键词后切到"动态"页再返回本地历史
- **THEN** 仍停在第 2 页且按该关键词筛选展示部分条目（或空态），未重新加载与重置

### Requirement: 本地历史记录标记和服务入口
本地历史 SHALL 使用与在线历史一致的居中瀑布流卡片，保留本地分页和当前页搜索；每张已保存卡片 SHALL 显示已记录及观看次数 badge，悬停显示全部真实观看时间/进度，单次也显示；页面 SHALL 提供独立定时服务管理入口。

#### Scenario: 已记录视频再次观看
- **WHEN** 同一视频以新的观看时间同步入库
- **THEN** 仍显示一张卡片，次数加一，旧观看时间保留；重复同步相同事件次数不增加。

#### Scenario: 管理定时服务
- **WHEN** 用户点击服务管理入口
- **THEN** 查询真实注册状态，未注册先提示确认注册，成功或已注册后打开独立管理窗口。

#### Scenario: 本地读取受限
- **WHEN** 初始化或读取 SQLite 因权限/锁定失败
- **THEN** 展示可重试错误，保留已加载内容，不崩溃且不当成空库。
