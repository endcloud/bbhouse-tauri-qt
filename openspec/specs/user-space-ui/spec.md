# user-space-ui Specification

## Purpose
定义视频卡片作者入口、个人空间资料与投稿/合集/专栏浏览、独立搜索及来源状态保持，并约束本地特别关注切换、过期响应隔离和主题布局行为。

## Requirements

### Requirement: 视频卡片作者入口

特别关注页之外的视频卡片 MUST 在拥有有效 UP 标识时允许点击 UP 主行打开应用内个人空间；行 MUST 提供主题一致的悬停/按下/键盘焦点突出与手形光标，支持键盘激活。作者点击 MUST NOT 同时触发视频播放或封面预览。标识 MUST 保留 64 位精度。特别关注页 MUST 保持作者行原交互。

#### Scenario: 点击视频作者
- **WHEN** 用户点击动态、稍后再看或历史视频卡片的有效作者行
- **THEN** 打开对应 UP 个人空间且视频不自动起播

#### Scenario: 特别关注与缺失作者
- **WHEN** 卡片处于特别关注页或作者 UID 缺失/无效
- **THEN** 作者行不展示可点击反馈且不进行空间跳转

### Requirement: 独立空间与返回

个人空间 MUST 在内容区提供返回入口，保持来源页实例、搜索、筛选、页码和滚动状态。空间 MUST 使用独立搜索与内容控制器，不修改特别关注页当前 UP。导航菜单切换 MUST 退出空间；同一 UP 不重复入栈。

#### Scenario: 返回来源
- **WHEN** 用户在筛选后的历史页进入空间再返回
- **THEN** 历史页恢复原搜索、页码及滚动位置且不重新加载

### Requirement: 资料头和本地关注

空间 MUST 显示头像、昵称、UID、投稿数量、刷新和本地特别关注状态；头像缺失/错误 MUST 使用内嵌默认图。资料加载失败 MUST 保留可用入口信息并提示重试。关注操作 MUST 合并已有本地列表、原子持久化并同步特别关注页，MUST NOT 写云端关注关系。

#### Scenario: 添加特别关注
- **WHEN** 用户点击设为特别关注
- **THEN** 本地列表包含该 UP，其他成员保持，界面显示已关注且特别关注页即时更新

#### Scenario: 快速切换与失败
- **WHEN** 切换 UP 后旧资料响应晚到或当前资料请求失败
- **THEN** 旧响应不覆盖当前资料，失败提示可见且可刷新重试

### Requirement: 空间内容浏览

空间 MUST 提供投稿、合集、专栏；投稿支持分区与最新发布/最多播放/最多收藏排序、每页 30 条服务端分页；合集每页 20 条并支持展开与播放；专栏全量加载后每页 30 条本地分页。空间 MUST 提供当前页已加载内容搜索、视频播放与封面预览，区分加载/失败/空结果。播放全部 MUST 仅播放当前页筛选结果并清楚标明范围。

#### Scenario: 筛选与分页
- **WHEN** 用户切换投稿分区或排序
- **THEN** 返回第一页并加载对应条件，旧条件晚返回不覆盖当前条件

#### Scenario: 播放当前页
- **WHEN** 用户点击投稿档播放全部
- **THEN** 按当前页筛选结果顺序打开播放器，空列表时禁用

#### Scenario: 主题与窄窗
- **WHEN** 切换明暗主题或收窄窗口
- **THEN** FluentUI 头部与内容区域保持可读，标题按钮不重叠，分页可操作
